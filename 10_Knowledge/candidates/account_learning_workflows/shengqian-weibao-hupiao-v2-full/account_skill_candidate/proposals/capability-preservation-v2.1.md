# 账号 Skill 能力保留与五页连续性 v2.1

## 用户确认

本账号是系统机制的验证样例，不是系统规则来源。用户明确要求：任何账号 Skill 的系统性升级或单独升级都必须继承旧能力；整体账号升级同样逐账号隔离，禁止跨账号污染。

## 本账号补齐

1. 以稳定能力 ID 记录 v1.0–v2.0 的方法路由、文案、视觉、查重、手部、版式、黄金回归、母版血缘、三页校准、来源隔离和生产闭环。
2. 旧 `.md` 扩展名、胡桃木默认桌面和“认可 AI 图承担食物母版”没有被删除历史，而是分别以用户确认的 TXT、账号黑灰桌面/后置餐具编辑、账号原图食物母版显式替代，并保留回滚。
3. 五张认可结果不再只是五个散列条目。新增有序回归包，完整记录无字完整餐母图、五页顺序、直接父关系和 5/5 文件哈希。
4. 五页回归包只用于连续性与构图回归；真实性、真实感、母版、黄金正例、方法证据和生成参考资格全部为 `false`。
5. 新内容仍由账号原图建立食物母版；同包页面优先裁切、标注和局部编辑。逐页整图重生必须新建包并重走校准，不能伪称继承连续性。

## 污染边界

- 本提案、能力清单和五页回归包只属于本账号。
- 系统层只保存字段、比较和错误规则，不包含本账号名称、菜品、桌面、餐具、页面或素材路径。
- 整体账号升级必须一账号一清单、一账号一验证，不建立跨账号能力池。

## 验收

- 旧能力 ID 0 丢失。
- 新能力差集与清单一致。
- 显式替换均有历史用户确认和回滚。
- 五页回归包 5/5 哈希、母图、页序和父关系通过。
- 同账号路径、系统污染、AI 来源权威和注册版本全部通过。
