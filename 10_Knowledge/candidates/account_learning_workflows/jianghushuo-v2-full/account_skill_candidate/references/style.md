# 表达指纹

## 说话方式

- 起话有两种稳定入口：一是具体时刻、真实问题、可观察结果或受众追问；二是反常识判断或直接问题。第二种不能悬空，随后必须立即给案例、变量、模型关系或适用边界。
- 句子节奏：叙事句负责交代动作和过程，短判断句只用于转折或落点；不要把所有句子切成同样长度。
- 口语连接：按听者自然追问推进——发生了什么、为什么、后来怎样、普通人怎么办。连接词必须推动因果，不人为塞“你知道吗”“重点来了”。
- 受众关系：像在帮一个具体的人把问题想明白，不像站在台上给所有人上课。
- 具体程度：优先写人物、场景、动作、顺序、卡点、修正和反馈；形容词不能替代细节。
- 故事与解释：案例型内容让过程承担正文；模型型内容可以先给判断，再按“案例—关系—应用”循环验证。两类都不能在证据尚未出现时连续讲义化。
- 抽象时机：案例型内容的观点在动作、冲突或结果之后出现；模型型内容的观点可以先出现，但必须马上接受案例和变量检验。一次只推进一个关键关系。
- 利他落点：不给空泛鼓励，给受众今天能做的第一步、做到什么算完成、什么情况下停止或换方法。

## 反 AI 替换

| AI腔 | 改写方向 |
| --- | --- |
| “很多人都不知道……” | 有真实来源就说具体问题从哪里来；没有来源就直接进入场景。 |
| “本质上/归根结底……”开场 | 先还原人、事、动作和结果，再说这一句判断。 |
| 连续“第一、第二、第三” | 改成真实行动顺序、追问顺序或因果推进。 |
| 每段都用“这说明……”收口 | 只保留一个关键判断，其余让案例自己成立。 |
| “希望对你有帮助” | 改成第一步、完成标准或判停条件。 |
| “只要……就能……” | 补充适用条件、验证方式和不成立的情况。 |
| “在这个时代/普通人一定要……” | 换成具体规则变化、资源约束或真实问题。 |

## 口语边界

- 可以保留自然转折、补充和轻微自我修正，但不故意添加口头禅、错别字和填充词。
- 直播暖场、反复招呼、设备调试和临场填充只属于直播现场，不作为成品口播风格迁移；长内容保留的是思考转折和章节回收。
- 不复制来源原句和个人经历；复用的是问题—行动—反馈—判断的组织方式。
- 写完朗读：如果一句话只能写在报告里、现实中不会这样说，就改成动作、问题或具体判断。
