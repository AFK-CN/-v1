# 发布文案生产规则

## 证据范围

- 账号学习 2.6 对 379 / 379 条可学习内容分别完成标题、正文、话题和发布协同观察，没有延期项。
- 标题中位长度约 17 字，正文中位长度约 164 字。稳定分工是“标题提出具体肤态、结果或选择承诺，正文提供过程与反馈，话题限定人群和场景”。

## 标题

优先从以下入口中选择一个：

1. 一种具体肤态、困扰或上妆/触感表现。
2. 一次真实使用、空瓶、回购或阶段复盘。
3. 一个产品选择、预算、肤质或场景分流问题。
4. 一套有明确适用条件的步骤或跟练任务。

- 标题可以写个人结果或强体验，但正文必须给出过程、观察证据和不适用边界。
- 不把个人变化写成人人有效、固定时效、诊断或治疗承诺。
- “好用、有效、修护、抗老、去闭口”等词不能独立成立，必须落到具体状态、条件和证据。
- 商业标题中的品牌、功效、价格和购买利益只来自当次简报、素材或已核验事实。

## 正文

- 自然经验：`起始肤态/问题 → 采取的动作 → 时间或频率 → 触感/状态反馈 → 继续、调整或停止条件`。
- 流程内容：`适用条件 → 步骤顺序 → 每步作用 → 观察点 → 判停点`。
- 产品决策：`共同问题 → 按肤质/状态/预算/场景分流 → 每项解决什么 → 谁不适用 → 选择建议`。
- 时间记录：时间只作观察坐标；变化、没有变化和不适都要如实写，不能把节点变成见效承诺。
- 个人感受、外部事实和商业主张分开表达；没有证据时降级或删除，不用百科知识填补经历缺口。

## 话题

- 使用目标人群/肤态、具体问题、本条形式或真实产品类别组成话题。
- 话题只描述正文与图片已经覆盖的内容，不补正文没有兑现的功效，不把高频标签当作方法触发器。
- 品牌、活动和商业权益仅在真实参与且有来源时添加；自然经验不继承广告标签强度。

## 标题、正文与视觉协同

`标题提出具体承诺 → 正文给过程、反馈和边界 → 图片/视频只证明可见状态 → 话题限定适用人群与场景`

- 标题、视觉开场、正文和话题必须服务同一个任务；三者冲突时，以完整正文、正式证据和医学边界为准，并降低标题强度。
- 前后图、肤态图和产品图只能支持画面可见内容；不能仅凭标题、OCR 或标签得出功效结论。
- 生活、社群和平台项目使用自己的事实与任务，不强行回到护肤结果。

## 发布前检查

- 标题承诺是否具体，且在正文中有过程、反馈和边界支撑？
- 是否把个人体验、产品事实和商业主张混成一个确定结论？
- 读者是否知道自己在什么条件下适用、观察什么、什么时候调整或停止？
- 话题是否放大了正文没有证明的功效或时效？
- 图片与正文是否只陈述可见事实，没有越过医学和真实性边界？
