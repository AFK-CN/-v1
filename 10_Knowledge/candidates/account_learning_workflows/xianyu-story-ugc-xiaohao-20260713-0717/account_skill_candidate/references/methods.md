# 方法路由

每次只选一个主方法。`xugc-m01` 是事实与价值的基础门；`xugc-m07` 只能作为可选表达支持。

## xugc-m01 具体事实先行，平台价值后置

- 触发：素材已有物件、动作、聊天和人物结果，需要提炼闲鱼连接价值。
- 固定：具体入口 → 人物变化 → 结果 → 可选价值解释。
- 不触发：只有品牌口号或没有人物变化。

## xugc-m02 物件痕迹、记忆、下一站

- 触发：物件有划痕、杂音、气味、页码或使用习惯，且有真实回忆和新用途。
- 固定：痕迹 → 记忆 → 转手阻力 → 新主人/新用途。
- 不触发：只有老物件题材，没有具体痕迹或下一站。

## xugc-m03 交易异常与关系反差

- 触发：主动补价、退还夹款、赠物、补偿或意外用途改变了交易判断。
- 固定：常规预期 → 反常动作 → 必要解释 → 即时关系结果。
- 不触发：只有“善良”评价，没有动作或聊天证据。

## xugc-m04 执行—反馈—身份增长双闭环

- 触发：同城服务、手作或技能有真实交付、客户反馈和收入/身份变化。
- 固定：最小起点 → 执行动作 → 阻力 → 反馈 → 变化。
- 不触发：只有收入数字或泛副业建议。

## xugc-m05 投入落差与退坑和解

- 触发：曾认真投入，但生活变化或能力落差导致搁置，转手能完成阶段性和解。
- 固定：最初承诺 → 具体投入 → 落差 → 转手 → 尊重过去。
- 不触发：只是清库存，或没有真实投入痕迹。

## xugc-m06 短交易奇遇及时止句

- 触发：素材核心只有一次异常消息、用途或动作，一个转折就能成立。
- 固定：异常开场 → 必要背景 → 单次转折 → 即时反应。
- 不触发：需要多轮执行才能理解，或素材本来是一段完整成长经历。

## xugc-m07 生活毛边表达支持

- 触发：事实链完整，素材中自然存在室友、家人、客户的误解或讲述者自嘲。
- 用法：只插入一处，缓冲过满的温情或成长叙事。
- 不触发：需要硬造段子，或笑点会嘲弄买家、老人、劳动者等人物。

## 组合

- `m02/m03/m04/m05` 依赖 `m01` 的事实先行边界。
- `m06` 与完整旧物故事、服务成长故事互斥，不要同时作为主结构。
- `m07` 可与 `m02/m04/m05` 组合，但删除它后主因果仍应成立。
