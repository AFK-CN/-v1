# 李宗恒候选方法组合与交叉验证设计

> 状态：阶段 2 候选设计，待用户确认。本文只定义如何组合和如何验证，不代表方法已经可调用。

## 1. 方法分层

### 前置证据门

- **G2 证据质量与账号归属门**：先确认逐字稿、画面、时间码和 source_id 是否支持结论；于洋、刘大悦er、大伟老三等只作为李宗恒作品中的共演关系，不拆成独立账号。
- **G1 内容轴分流与广告植入学习门**：区分正常内容、剧情完整植入、广告主导和平台活动。商业内容不进入正常选题频次和 V1 自然方法证明，但必须继续拆解广告前正常剧情、引入桥、产品剧情角色和广告后收束，不能直接跳过。

### 主冲突方法

- **M1 整套系统迁移**：冲突来自一套制度被完整搬到另一场景。
- **M2 评价权与控制权反转**：冲突来自谁有权提问、定义、服务或审批发生变化。
- **M3 字面重释与双语境链**：冲突来自同一句话被另一套字面、指代或语境解释驱动。

### 递进发动机

- **M4 固定规则多场景递进**：它负责把一个已经成立的冲突发动机重复、升级和收束，通常不是独立的冲突来源。

### 支持层

- 标题、发布文案、话题、短句和悬念只负责入口与表达包装。
- 正常/自己对照、信息差、揭示和末尾反转只作为通用结构容器或收束手段。
- 支持层不能单独触发账号方法，也不能覆盖证据门结论。

## 2. 固定调用顺序

```text
G2 证据充分性
  -> G1 正常/商业/平台分流
  -> 正常内容：在 M1/M2/M3 中选择一个主冲突方法
  -> 正常内容：需要多轮升级时叠加 M4
  -> 商业内容：先识别广告前正常剧情发动机
  -> 商业内容：选择 B1-B5 引入桥并检查产品角色和广告后收束
  -> 选择标题/文案/话题包装
  -> 再次执行 G1/G2 边界检查
```

不允许看到关键词后自动把 M1、M2、M3 全部叠加。主方法由“冲突因果”决定，而不是由题材名词决定。

商业内容的五类引入桥为：B1 沿用同一剧情发动机、B2 产品作为悬念真相、B3 角色需求与关键道具、B4 产品功能具象为世界规则、B5 剧情外壳后集中口播接管。B5 只作为低融合边界，不因数量多而优先复用。

## 3. 交叉使用矩阵

| 组合 | 是否建议 | 使用条件 | 不能混用的情况 |
|---|---|---|---|
| M1 + M2 | 可以 | 系统迁移同时改变评价权或流程控制权 | 只有换场景，没有权力动作变化 |
| M1 + M4 | 强组合 | 新系统需要按多个流程环节逐轮兑现 | 只替换一个名词或一个道具 |
| M2 + M4 | 强组合 | 同一控制权反转需在多轮问答/服务动作中升级 | 只有结尾一次身份翻牌 |
| M3 + M4 | 强组合 | 一个双义解释可在多个行动中连续产生后果 | 只有孤立谐音梗 |
| M1 + M3 | 谨慎 | 系统规则本身通过语言重释执行，且两条因果链均可证明 | 实际冲突只来自制度或只来自词义时，必须择一 |
| M2 + M3 | 谨慎 | 语言解释直接夺取定义权或提问权 | 只是在权力场景里说了双关词 |
| M1 + M2 + M3 | 默认禁止 | 只有三条独立机制均通过消融测试才允许 | 关键词同时出现不构成三方法组合 |

## 4. 交叉验证

### V1 跨内容稳定性

- 至少 3 条独立正常内容，覆盖至少 2 种关系或场景。
- 同一系列的多个近重复作品只计一次独立证据。
- 广告、品牌定制和平台活动不能证明账号自然方法频次。

### V2 预测指导力

- 给出未见过的新题材，只提供任务信息，不提供方法名。
- 方法必须能预测结构步骤、触发条件或边界，而不只是解释已发生案例。
- 预测结果必须能被单卡或脚本结构检查。

### V3 账号独特性

- 与“普通反转”“一般误会”“常规对照”“短标题”等行业通用模式比较。
- 若删除账号特有机制后结论仍完全成立，则降级为支持层。
- 与兄弟方法做互斥判断，不能每个任务都同时命中多个方法。

### 消融、迁移和干扰测试

1. **词汇诱饵**：保留题材词，删除机制关系，应判定不触发。
2. **机制迁移**：替换人物、场景和道具，保留因果机制，应判定触发。
3. **兄弟干扰**：同一任务分别送入 M1/M2/M3，只允许最能解释冲突因果的方法成为主方法。
4. **组合增益**：比较主方法单独使用与“主方法 + M4”；M4 必须只增加递进与强度，不能偷换核心冲突。
5. **商业双轨**：广告样本不能增加自然方法权重，但必须完整产出“正常剧情发动机、引入桥、产品角色、广告后收束”；只隔离不学习同样判失败。
6. **证据追溯**：每个通过结果必须保留 source_id、证据类型；视觉和商业结论还必须保留时间码。
