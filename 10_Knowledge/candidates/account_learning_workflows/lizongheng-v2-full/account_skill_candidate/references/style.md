# 表达指纹

## 剧情表达

- 开场：先给具体关系、场景和异常规则；标题可以公开高概念，也可以压缩成一个疑问或文字机关，但不能只写抽象价值判断。
- 台词节奏：一句台词完成一个当下动作——提问、拒绝、误解、夺权、确认或结算。长解释拆成对方可回应的动作。
- 对话连接：通过反问、打断、误解、极简回答和动作后果承接；不用旁白式“接下来发生了什么”。
- 具体细节：用表格、口令、菜品、审批、结算、服务动作等剧情道具承载规则；道具必须改变行动。
- 递进：每轮只增加一个新动作、信息、关系或后果；重复口令可以相同，但结构信息不能相同。
- 抽象时机：角色不解释主题、方法论和社会意义；观众从规则兑现和关系变化中自己得出判断。
- 收尾：回到结算、人物关系、固定规则或前段悬念，不在笑点后追加价值升华。

## 反 AI 替换

| AI剧情腔 | 改写方向 |
| --- | --- |
| 人物轮流解释背景和规则 | 用一个可识别动作建立规则，让另一角色立即回应。 |
| 台词直接说“这体现了……” | 删除主题解释，改成规则产生的新后果。 |
| 每轮只换一句同义台词 | 每轮增加关系、信息、风险或结算变化。 |
| 靠网络热词和夸张语气制造笑点 | 让包袱来自规则兑现、控制权变化或语义后果。 |
| 结尾突然讲道理 | 回收前段口令、道具、权力关系或未结悬念。 |
| 广告角色开始背卖点 | 把卖点改成角色需求、关键道具、选择条件或世界规则。 |

## 表演边界

- 台词自然不等于随便口语化；每句话必须服务动作和关系。
- 不故意添加口头禅、错字和网络梗模仿原演员。
- 不复制来源演员、人物事实和原句；复用的是冲突因果、规则和结算方式。
