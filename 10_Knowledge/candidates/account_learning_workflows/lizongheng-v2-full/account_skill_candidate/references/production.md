# 生产机制

## 选择顺序

1. 先分流自然短剧情、商品广告或平台项目。
2. 自然剧情只选 M1/M2/M3 中一个主冲突；M4 只负责递进，不替代主冲突。
3. 写清观众一眼能懂的旧常识、异常规则和最终结算。
4. 先设计动作节点，再写台词；没有动作变化的台词不算升级。

## 四个剧情发动机

### M1 整套系统迁移

- 适用：两个现实系统都能被快速识别，迁移后可以持续决定人物行动。
- 固定单元：目标场景矛盾 -> 源系统角色/流程/术语/结算至少三层映射 -> 三个以上规则驱动动作 -> 新系统结算。
- 可变槽位：关系、目标场景、源系统、映射层数、最终代价。
- 完成门：结尾仍由迁移规则决定；删掉映射后剧情应无法成立。

### M2 评价权与控制权反转

- 适用：原场景有清晰的提问、定义、审批、服务或评价权。
- 固定单元：旧权力关系 -> 一个夺权动作 -> 至少两个流程动作兑现新权力 -> 原权力方被迫接受规则或后果。
- 可变槽位：权力类型、关系、夺权动作、流程节点和后果。
- 完成门：反转改变了流程，不只是角色态度更强硬。

### M3 字面重释与双语境链

- 适用：同一句话能建立语言上自洽的第二解释，并驱动行动。
- 固定单元：原意 -> 替代解释 -> 角色按替代解释行动 -> 后果强化误读 -> 语义回收。
- 可变槽位：关键词、关系、语境、行动和后果。
- 完成门：不需要长篇解释也能理解；只有双关没有行动时不成立。

### M4 固定规则多场景递进

- 适用：已有一个清晰主冲突或人物执念，需要多轮升级。
- 固定单元：一句话规则 -> 至少三轮共享发动机 -> 每轮增加关系/信息/风险/后果之一 -> 最后一轮改变对象、暴露最高代价或完成回收。
- 可变槽位：场景、轮次、升级维度、结算对象。
- 完成门：三轮可以排序；删掉中间一轮会损失信息或强度，而不是只缩短时长。

## 共用机制

- 张力：观众先理解规则，再等待规则在下一动作中产生什么后果。
- 可信与连续性：人物动机、关系和每轮动作必须连续；包袱不能靠人物突然变笨。
- 理解：异常规则能用一句话复述，台词通过行动兑现，不安排角色解释创作方法。
- 受益：自然剧情交付的是识别感、关系反差和结算快感；不强加知识口播式行动建议。商业内容的产品利益必须有证据。
- 篇幅：普通剧情完成设定、两个以上有效动作、结算和关系回收即可；M4 必须至少三轮且逐轮升级，不靠重复填充。

## 商品广告

1. 先写脱离产品仍能成立的正常剧情发动机。
2. 再选广告引入桥：同发动机延续、结果揭示、角色需求/关键道具、世界规则或低融合载荷接管。
3. 明确产品在剧情中的角色和卖点载荷；卖点不能让角色突然开始背说明书。
4. 广告后必须回到原冲突、关系或前段悬念；集中口播接管属于低融合边界方案。

## 平台项目

先确认外部项目壳、账号参与角色和发布任务；只学习参与方式和发布协同，不计入自然方法频次，也不硬套商品广告结构。

默认交付包括内容轨道、关系与冲突、标题、文案、话题、黄金三秒、完整脚本、方法和内部证据参考。内部额外记录主冲突、固定规则、可变槽位、升级轮次和结算方式。
