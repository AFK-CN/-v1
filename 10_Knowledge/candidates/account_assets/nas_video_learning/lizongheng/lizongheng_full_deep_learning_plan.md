## 这次分类怎么改

之前的问题是发布文案太短，很多作品只写标题或话题，单靠文案会把段子内容误分成泛生活、情感、广告等杂类。新方案改成多维分类：

1. 内容形态：剧情段子 / 唱演表达 / 口播独白 / 合拍同框 / 其他。
2. 人物关系：恋爱婚恋 / 亲友家庭 / 职场商务 / 校园同学 / 朋友社交 / 陌生人服务消费 / 自我表达舞台 / 待判定。
3. 场景类型：家庭节日 / 职场会议 / 校园宿舍 / 餐饮购物 / 公共空间 / 舞台媒体 / 泛生活室内 / 待判定。
4. 喜剧机制：误会错位 / 身份错位 / 语言歧义 / 边界拉扯 / 情绪升级重复 / 地位反转 / 最后反转 / 金句价值表达。
5. 广告轴：正常内容 / 剧情完整的植入 / 广告强绑定 / 平台活动 / 待判定。
6. 学习价值：结构样本 / 人设表演样本 / 标题文案样本 / 广告隔离样本 / 低信息样本。

## 广告隔离规则

广告不再污染内容方向。它作为独立广告轴处理：一条作品可以同时是“恋爱婚恋 + 误会错位 + 广告植入”。

- 正常内容：剧情闭环完整，品牌/购买信息不推动主冲突。
- 广告植入但剧情完整：剧情可学习，但产品是关键道具或解决方案。
- 广告强绑定/广告主导：主要目标是卖点、福利、活动，剧情只服务转化。
- 平台活动：挑战赛、任务型内容，不进入账号核心方向统计。
