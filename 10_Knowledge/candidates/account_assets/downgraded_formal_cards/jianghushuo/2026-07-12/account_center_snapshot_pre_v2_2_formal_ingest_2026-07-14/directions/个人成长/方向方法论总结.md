## 1. 方向核心判断

姜胡说的“个人成长”不是泛励志，也不是单纯自律鸡汤，而是一套“低压力行动 + 问题驱动学习 + 公开输出反馈 + 复盘迭代”的成长系统。

这个方向的核心不是让用户变得更努力，而是让用户把成长动作变小、变具体、变可重复、变可被反馈。它常见的底层逻辑是：

- 学习必须进入真实问题和真实项目，否则容易变成收藏、囤课和自我安慰。
- 改变不靠高压自律，而靠低版本动作、微习惯和持续重复。
- 输出不是等自己厉害以后才做，而是在公开学习、公开工作中获得反馈。
- 结果目标容易制造焦虑，过程目标更可控，也更容易长期坚持。
- 个人成长最终要能留下作品、记录、复盘和可被别人发现的价值。

## 3. 共性方法论

### 3.1 项目驱动学习

不要先系统学完再开始，而是先进入一个真实项目。项目会制造真实问题，问题会倒逼学习，学习结果又可以被记录和分享。

可复用动作：

1. 找一个够得着的小项目。
2. 在项目中暴露不会的问题。
3. 只学当下能用的部分。
4. 把解决过程写下来或讲出来。
5. 用是否有人因此信任你、找到你，判断学习是否产生价值。

### 3.2 问题驱动自学

学习不是从“别人推荐什么”开始，而是从“我现在要解决什么问题”开始。书、访谈、课程、案例都只是问题的材料库。

可复用动作：

1. 定义当前问题。
2. 判断问题卡在概念、案例、方法还是行动。
3. 选择能补这一块的材料。
4. 学完后必须进入使用场景。

### 3.3 凿洞学习法

读书和学习不要从第一页被动吸收，而是先制造认知缺口。

三步：

1. 定位：从目录或问题出发，找到核心章节。
2. 凿洞：合上书，先提问、猜测、预判。
3. 入钉：带着问题读，并在 24 小时后复述或使用。

### 3.4 低版本成长法

个人成长的关键不是“更狠”，而是“更能长期重复”。过高目标会触发焦虑和自责，低版本动作能绕开大脑防御。

判断标准：

- 做完后更放松，可以继续。
- 做完后被耗尽，需要降级。

### 3.5 微行动身份法

行动不是动力的结果，行动会制造动力。身份不是靠口号改变，而是靠每天重复的小动作塑造。

公式：

```text
改变 = 天数 × 重复
身份 = 长期重复动作的结果
```

### 3.6 公开学习法

收藏不等于学习。真正的学习需要应用、表达和反馈。可以在大庭广众下学习，公开自己的理解、使用、失败和修正。

标准表达：

```text
我也在学习，这是我的体会和理解。
我准备这样用它，但这里可能还不成熟。
你们有什么看法和建议吗？
```

### 3.7 测试复盘法

面对内容、项目和行动结果，不要用成功/失败评价自己，而要用测试心态提取反馈。

公式：

```text
错误 + 反思 = 进步
数据 = 反馈，不是人格否定
```

## 4. 常见内容结构

### 4.1 反常识纠偏型

结构：

1. 抛出反常识观点。
2. 指出常见做法为什么无效。
3. 解释背后的心理或学习机制。
4. 给一个更低门槛的替代动作。

代表：

- 不要太自律。
- 不要从第一页开始读书。
- 收藏夹不是知识库，而可能是知识火葬场。

### 4.2 方法命名型

结构：

1. 给方法命名。
2. 拆成 2-3 个步骤。
3. 用生活场景解释。
4. 给观众一个今天能做的动作。

代表：

- 凿洞学习三步法。
- 小到不可能失败。
- 大庭广众下学习。

### 4.3 成长案例型

结构：

1. 先给结果或转折。
2. 回到当时的问题。
3. 展示具体动作和复盘。
4. 提炼为普通人可复用的方法。

代表：

- 项目驱动学习带来客户。
- 短视频从 0 到破万。
- 每天写和每天输出带来长期变化。

### 4.4 日常动作型

结构：

1. 说明一个不起眼动作的重要性。
2. 解释为什么大目标不如小习惯。
3. 给出过程目标。
4. 强调长期重复后的身份变化。

代表：

- 每天准备一份礼物。
- 每天写一点。
- 每天一小时做方向正确的小事。
