# 小红书与抖音差异 v1

## 小红书

优先判断：

- 收藏价值。
- 搜索价值。
- 是否能照着做。
- 是否有清单、步骤、模板、菜单。
- 是否有人群和场景标签。

更适合：

- 图文清单。
- 教程。
- 菜单。
- 经验贴。
- 可保存的工具型内容。

第一版观察：

- 当前小红书样本中，收藏和分享高的内容多为“一周菜单”“备餐指南”“独居一人食”。
- 对小红书来说，标题和正文要让用户立刻知道“收藏后能解决什么问题”。

## 抖音

优先判断：

- 前 3 秒是否有强观点。
- 是否能引发评论复述。
- 是否有分享给别人的理由。
- 是否把抽象道理压缩成动作、公式或金句。

更适合：

- 口播。
- 强观点。
- 行动建议。
- 个人成长。
- 自媒体方法论。

第一版观察：

- 当前抖音高表现内容常见结构是：强观点开头 -> 解释新规则 -> 具体行动建议 -> 金句收束。
- 评论区高赞内容会主动总结、补充、类比，这是判断内容是否进入用户心智的重要证据。
