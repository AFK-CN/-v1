# 李宗恒内容输出标准模板

账号 Skill 版本：1.4

权威来源：`skill/references/production.md` 与 `skill/references/publishing-copy.md`。固定单元必须由动作兑现；可变槽位必须改变剧情因果，不能只换名词。脚本完成后另压缩一条设定/疑问型发布文案，不提前解释完整笑点和结算。

## 模板一：整套系统迁移 M1

```text
目标场景：【关系 + 熟悉矛盾】
源系统：【另一套观众熟悉的制度】

旧常识动作：原本应该由谁做什么？
异常规则：哪套系统被完整迁入？

映射 1——角色：A 对应谁，B 对应谁？
映射 2——流程：原场景要按什么新流程走？
映射 3——术语或道具：哪个口令、表格或物件改变行动？
映射 4——结算：最后按哪套制度付出代价或得到结果？

动作一：【规则第一次兑现】
动作二：【出现更具体后果】
动作三：【关系、风险或结算升级】
最终结算：【仍由迁移规则决定】
```

完成门：删掉制度映射后，剧情无法成立；不能只有服装、道具或名词错位。

## 模板二：控制权反转 M2

```text
旧权力关系：谁提问/审批/评价/服务，谁被动接受？
夺权动作：被动方用什么具体动作拿走控制权？
流程动作一：新权力如何改变提问、选择或审批？
流程动作二：原权力方被迫执行什么规则？
更高后果：关系、信息或代价如何升级？
结算：原权力方最终接受什么后果？
```

完成门：反转改变了流程，不只是弱者突然变强硬。

## 模板三：字面重释 M3

```text
原语境：这句话通常是什么意思？
关键词：【能产生第二解释的词】
替代解释：第二种解释为什么在语言上自洽？
行动一：角色按新解释做了什么？
后果一：另一角色如何回应？
行动二：误读如何继续影响选择或关系？
语义回收：结尾如何让原意和替代解释碰撞？
```

完成门：不用长篇解释也能理解；第二解释必须驱动行动和后果。

## 模板四：固定规则递进 M4

```text
主冲突方法：【M1 / M2 / M3，只选一个】
一句话规则：【观众能复述】

第一轮：规则第一次兑现，建立基础后果。
第二轮：新增【关系/信息/风险/后果】。
第三轮：再新增另一维度，暴露更高代价。
最后一轮：改变对象、完成最高结算或回收前段规则。
```

完成门：轮次可以明确排序；删掉中间一轮会损失信息或强度。

## 商品广告附加模板

```text
正常剧情发动机：【M1 / M2 / M3，拿掉产品仍成立】
广告引入桥：【同发动机延续 / 结果揭示 / 角色需求或关键道具 / 世界规则 / 低融合接管】
产品角色：产品在人物行动中解决什么真实任务？
卖点证据：哪些信息有独立素材支持？
广告后回收：如何回到原冲突、关系或悬念？
```

## 统一发布包

- 内容轨道与人物关系。
- 一句话旧常识和一句话异常规则。
- 标题：公开高概念、疑问或文字机关之一。
- 黄金三秒：关系 + 场景 + 第一个异常动作。
- 完整脚本：动作节点先于台词。
- 发布文案和话题：不替代剧情信息。
- 内部记录：主冲突、固定规则、可变槽位、升级轮次、结算方式和证据。
