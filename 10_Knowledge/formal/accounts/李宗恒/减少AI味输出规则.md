# 李宗恒减少 AI 味输出规则

账号 Skill 版本：1.4

权威来源：`skill/references/style.md`、`production.md`、`publishing-copy.md` 与 `boundaries.md`。剧情账号的“去 AI 味”重点是动作与关系成立，不是给台词堆语气词，也不是把极短发布文案扩成 AI 式剧情总结。

## 最容易出现的 AI 剧情腔

| 不要这样写 | 改成什么 |
| --- | --- |
| 人物轮流解释背景和规则 | 用一个动作建立规则，让另一角色马上回应。 |
| 台词直接说“这体现了……” | 删除主题解释，改成规则产生的新后果。 |
| 每轮只换一句同义台词 | 每轮增加关系、信息、风险或结算变化。 |
| 靠网络热词和夸张语气制造笑点 | 让包袱来自制度兑现、控制权变化或语义后果。 |
| 人物突然降智配合反转 | 补足人物动机，让他按已建立的信息行动。 |
| 结尾突然讲道理 | 回收前段口令、道具、权力关系或未结悬念。 |
| 广告角色开始背卖点 | 把卖点变成角色需求、关键道具、选择条件或世界规则。 |

## 台词怎么写得像真人

- 一句台词只做一个动作：问、拒绝、打断、确认、误解、夺权或结算。
- 对方下一句必须回应刚才的动作，不能像两个人分别朗读完整观点。
- 长背景拆成能被打断、质疑或执行的短动作，不安排角色自报创作设定。
- 可以有极简回答和重复口令，但重复后必须产生新后果。
- 不故意加网络梗、口头禅、错字和夸张标点模仿“真人感”。

## 规则怎么避免模板味

不能只把“公司换成家庭”“审批换成相亲”就算新剧情。每条新内容至少更换真实关系、控制权、动作链或结算代价中的关键变量，而且新变量必须改变后续行动。

M1 要能列出角色、流程、术语和结算的多层映射；M2 要能指出控制权在哪个动作中转移；M3 要能追踪替代解释如何驱动后果；M4 要能说明每轮新增了什么。

## 收尾检查

1. 最后一个笑点是否由前面规则自然产生？
2. 有没有角色替创作者总结主题？有就删。
3. 删除某轮后，信息和强度是否毫无损失？有就说明这一轮重复。
4. 拿掉夸张语气和网络热词，冲突是否仍成立？
5. 人物是否因为剧情需要突然变笨或忘记前一轮信息？
6. 广告内容拿掉卖点后，正常剧情是否还能独立成立？
