# 本账号 Skill 升级兼容边界

机器入口：`../UPGRADE_COMPATIBILITY.json`。该文件是本账号 v1.0–v2.1 的能力账本，不是新的账号方法。

## 保留原则

- 视觉多图、发布文案、完整包查重、动态步骤页、固定手部、教程版式轮换、黄金回归、视觉血缘、三页校准、来源隔离和生产记忆闭环均使用稳定能力 ID。
- 升级可以增加约束或替换实现，但旧 ID 不能消失。历史 `.md` 扩展名、胡桃木默认值和“认可 AI 图承担食物母版”已经由用户后续明确改为 TXT、账号黑灰桌面与账号原图食物母版；这些旧实现保留为显式历史与回滚，不再作为当前默认。
- 五张用户认可结果作为完整回归包保留。它们共同校验页面连续性和构图，不能拆散后只留下文案或两个锚点；同时不能升级为食物真实感来源。

## 升级门

1. 比较 `previous_capability_ids` 与当前 `capabilities`，任一旧 ID 缺失直接失败。
2. 检查关键 Skill 文件哈希，防止文件变化未登记。
3. 检查每条能力来源仍位于本账号目录，禁止借用其它账号规则、资产或结论。
4. 检查五页回归包的母图、页序、父关系与哈希。
5. 替换或弃用必须绑定同账号提案、用户确认和回滚。

失败时恢复 v2.0 文件与注册版本；保留 v2.1 提案、兼容清单和失败报告，不删除任何原图、历史锚点或正式知识。
