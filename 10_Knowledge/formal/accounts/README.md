# 正式账号中心

本目录只保存已经人工确认生效的账号知识与账号 Skill。每个账号必须是本目录的直属子目录：

```text
accounts/{账号}/
├── ACCOUNT_SKILL_MANIFEST.json
├── skill/
├── 账号整体方法论.md
├── 内容生产使用说明.md
├── 减少AI味输出规则.md
├── 内容输出标准模板.md
├── directions/
├── methods/
└── evidence/
```

这里不建立主题子库、平台子库或“账号中心”中间层。跨账号主题归纳只进入 `10_Knowledge/candidates/`，经单独立项和人工确认后再决定正式归属。
