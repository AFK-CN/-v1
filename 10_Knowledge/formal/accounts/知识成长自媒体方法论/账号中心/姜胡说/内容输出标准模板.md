# 姜胡说内容输出标准模板

状态：formal_ingested  
用途：账号通用输出模板。用户要求出选题、写口播、写长文案、做批量内容时按此模板组织；具体素材从正式方向、单卡、粗扫线索中调用。

## 1. 选题模板

| 字段 | 要求 |
|---|---|
| 选题标题 | 一句话讲清具体问题或具体收益，不写空泛大词。 |
| 任务方向 | 赚钱/创业/短视频/表达文案/阅读输入等，可多方向组合。 |
| 对应方法论 | 写清来自哪个方向的哪个方法，例如“问题—方案—验证—杠杆”。 |
| 受众痛点 | 具体人群的具体卡点。 |
| 黄金3秒角度 | 误区纠偏、普通人直问、具体场景、风险自测、行动承诺、反常识判断等。 |
| 核心观点 | 一句话说明这条内容要证明什么。 |
| 可引用案例 | 优先正式单卡；粗扫线索必须标注未深学验证。 |
| 对标知识库内容 | 文件路径、source_id、来源层级。 |
| 原抖音链接 | `https://www.douyin.com/video/{source_id}` 或卡片中的原链接。 |
| 证据边界 | 哪些能说，哪些不能外推。 |

```text

【具体误区/具体场景/反常识判断】

正文：

而是【更准确的问题定义】。

姜胡说这套方法里，关键不是【错误动作】，
而是先做三件事：

3.【动作三】

【source_id 对应单卡案例或方向总结中的案例】

收束：
今天先不要做大计划。
先完成【一个最小动作】。

证据来源：
- 对标知识库内容：
- source_id：
- 原抖音链接：
- 来源层级：
- 证据边界：
```

## 3. 长文案模板

```text
标题：
【具体问题 + 反常识判断】

开头：
先用一个普通人场景切入，不要写宏大背景。

第一部分：误区
指出用户以为自己缺什么，实际卡在哪里。

第二部分：方法
用方向方法论拆 2-4 个动作。

第三部分：案例
引用正式单卡案例；如果来自粗扫，必须写“粗扫线索，未深学验证”。

第四部分：行动
给一个今天能做的小动作。

结尾：
用问题或行动提醒收束，不机械写“你学会了吗”。

证据来源：
- 对标知识库内容：
- source_id：
- 原抖音链接：
- 来源层级：
- 证据边界：
```

## 5. 批量输出模板

批量输出时，每条都必须保留：

```text
1. 选题标题：
2. 黄金3秒：
3. 核心观点：
4. 对应方向/方法论：
5. 可引用案例：
6. 对标知识库内容：
7. source_id/原抖音链接：
8. 来源层级：
9. 与上一条不同点：
```

批量防偷懒要求：

- 不同条目必须有不同钩子角度。
- 不同条目必须有不同具体场景或动作。
- 不允许只换关键词。
- 不允许所有条目都指向同一张卡，除非用户明确要求围绕单卡扩写。
