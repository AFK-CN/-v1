## 1. 方向核心判断

姜胡说的短视频方法不是“多拍、追热点、背稿、套技巧”，而是把短视频嵌入真实做事与持续成长的系统：先明确目的和用户，以真实问题与经历作为输入，用稳定结构讲清价值，再通过有目的的发布实验和复盘，把有效内容沉淀为关系、知识和商业资产。

核心闭环：

```text
做真实的事
-> 记录卡点、经验与灵感
-> 结构化为可运行知识卡
-> 用稳定形式自然表达
-> 每条只测试少量变量
-> 按目标复盘反馈
-> 沉淀内容、关系与创作系统
```

## 3. 共性方法论

### 3.1 先做事，再拍内容

- 普通人的稳定内容源不是凭空想选题，而是正在做的一件具体事。
- 卡点、失败、尝试、突破和结果共同构成学习曲线。
- 短视频是成长过程的副产品，不应反过来吞噬全部生活。

### 3.2 真实经历必须结构化

- 原始经历先用朴素语言记录，不追求文采。
- AI用于提取问题、原因、方法、结果与条件，不能代替个人经验。
- 知识卡长期连接后，可复用为口播、文章、课程和咨询。

### 3.3 说什么与怎么说分开

- “说什么”必须来自自己的观点、经历与验证。
- “怎么说”可逆向成熟样本，固定两三种结构反复练习。
- 固定形式后，把主要注意力放在一句话核心和内容深度。

### 3.4 新手期是探测期

- 多拍是为了测试，不是为了堆数量。
- 每条提前声明测试变量：选题、开头、结构、表达、形象或承接。
- 发布后记录用户、评论、目标指标、可复用元素和下一步变化。
- 方向长期无效要及时止损；不能用勤奋回避方向判断。

### 3.5 最终资产是关系与系统

- 流量和热点属于平台，用户信任与主动回访才属于创作者。
- 有用建立记忆，真实建立信任，持续一致形成关系。
- 输入、处理、表达、反馈和复盘稳定后，才形成可复利的创作系统。

## 4. 常见内容结构

1. 问题解决型：你是否遇到问题 -> 我的真实证据 -> 具体方法 -> 结果与条件。
2. 学习曲线型：第几天/周 -> 卡点 -> 多种尝试 -> 对比 -> 突破 -> 下一步。
3. 反常识型：大家以为 -> 实际不是 -> 原因 -> 新原则 -> 行动建议。
4. 三段系统型：错误认知 -> 系统框架 -> 操作步骤 -> 反馈闭环。
5. 形式教学型：低门槛处境 -> 形式一/二/三 -> 具体画面与声音 -> 鼓励行动。

## 5. 高频黄金 3 秒钩子类型

- 直接纠错：很多人对短视频的理解都是错的。
- 结果承诺：一条视频给你讲清楚怎么拍短视频。
- 低门槛共情：不敢露脸、不会说话，但想做短视频，怎么办？
- 反灵感：你以为拍短视频靠灵感，其实不是。
- 极简结论：做短视频其实就两个，有用和真实。
- 最佳方法：普通人做短视频最有效的方法是什么？

## 6. 常见收尾与互动引导

- 行动建议：给自己制定一个半年或一年的小计划，并开始记录学习曲线。
- 收藏提醒：把完整框架收藏，在卡住时逐项检查。
- 原则复述：有用、真实。
- 鼓励式收束：愿意认真体会生活，就能找到可拍内容。
- 多数视频没有明确评论引导，不应补造互动话术。

## 7. 可复用选题池

- 我做[项目]第1天遇到的第一个卡点。
- 同一个问题，我测试了三种方法，只有一种有效。
- 为什么一天拍一百条仍然做不好账号？
- 你的流量是平台资产，还是自己的关系资产？
- 不露脸、不口播也能做的三种内容。
- 如何把一次踩坑变成一张知识卡和一条口播？
- 为什么背稿让你的内容更不像自己？
- 新账号前十条应该分别测试什么？
- 发布一条视频后，真正需要复盘哪些字段？
- 有用和真实，为什么比技巧更能积累信任？
