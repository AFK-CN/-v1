# 子知识库：知识成长 / 自媒体方法论

状态：active，已由你确认转正。

## 定位

这个子知识库服务两类核心任务：

1. 把知识成长、行动系统、自媒体创作相关案例沉淀为可复用方法论。
2. 支持小红书和抖音的选题、脚本、图文、周复盘和方法论进化。

## 当前数据基础

- 抖音内容 709 条。
- 抖音评论 5970 条。
- 创作者样本主要集中在 `姜胡说`。

## 可支撑的输出

- 抖音短视频脚本。
- 小红书知识类图文改写。
- 普通人行动系统选题。
- 自媒体成长、内容创作、复盘方法论。
- 评论区洞察驱动的二创选题。

## 当前方法论方向

- 强观点开头：用一句反常识判断抓住注意力。
- 普通人行动承诺：降低门槛，强调每天小投入。
- 过程目标替代结果目标：减少焦虑，提高执行感。
- 评论区共创：用户高赞评论会复述、总结、补充方法。
- 方法公式化：把复杂认知压缩成几个步骤或公式。

## 使用方式

当你要做知识成长、自媒体、行动方法、普通人副业、内容创作相关内容时，优先调用本子库。

推荐指令：

```text
基于知识成长/自媒体方法论子库，给我生成 10 个抖音选题。
```

```text
调用知识成长/自媒体方法论子库，把这个观点改成小红书图文。
```

```text
基于这个子库和本周数据，复盘哪些方法论被验证。
```

## 风险和补充需求

- 当前样本集中在单一作者，需要后续补充更多创作者，降低风格偏差。
- 抖音高指标不能直接等于小红书可复用，需要按平台重写。
- 知识成长内容容易空泛，输出时必须保留具体行动、具体场景、具体人群。
