# 表达指纹

## 开场与推进

- 从具体肤态、当天状态、生活场景或选择难题开场。可以打招呼，但两三句内必须落到这次要解决的具体问题。
- 口语可以松，但每句话要新增条件、动作、感觉或反馈；不要把同一句道理换词重复。
- 条件连接词优先用自然说法，例如“如果你也是这种状态”“我当时先做了什么”“后来发现”“这个时候就别继续了”。只有因果真的存在时才使用，不机械植入。
- 把读者当成一个正在经历相似问题的人来讲。“姐妹”“宝宝”可以偶尔出现，但不能每句都叫，也不能用称呼代替有效信息。

## 细节与解释

- 优先保留质地、触感、时间、频率、使用前后状态，以及为什么继续、调整或停止。
- 先讲真实过程，再给有限解释。解释只能到证据允许的位置，不能把个人判断升级成医学事实。
- 抽象结论放在经历和反馈之后，让读者先看见“发生了什么”，再听“我怎么理解”。
- 产品逐项说明解决什么、适合谁、为什么保留、什么情况下不用。
- 标题、正文、话题和视觉开场服务同一任务，品牌词和标签不反向决定方法。

## 利他落点

成品至少帮助读者完成一件具体的事：知道怎么选、知道先试哪一步、知道观察什么，或者知道什么时候该停。

## 去除 AI 味的替换规则

| 容易出现的写法 | 改成 |
| --- | --- |
| 先讲一大段百科式成分知识 | 先讲这次真实问题、动作和使用反馈 |
| “适合所有肤质”“大家都可以” | 按肤质、状态和使用条件分支 |
| 温和、清爽、好吸收等形容词堆叠 | 写触感、状态变化和具体观察证据 |
| “坚持使用就会……” | 写观察周期、可能反馈和停止条件 |
| “希望对你有帮助”式泛结尾 | 给下一步动作、观察点或判停点 |
| 连续罗列产品 | 先建立选择条件，再把产品放进分支 |
| 用临床确定口吻解释个人变化 | 明确这是个人经验，并标出证据等级与边界 |

## 口语边界

- 不靠故意错字、碎句、口头禅和大量语气词制造“真人感”。
- 不高频重复“姐妹”“宝宝”等称呼。
- 不复制原账号句子、个人经历或独特口头禅；学习的是表达机制，不是表面仿写。
