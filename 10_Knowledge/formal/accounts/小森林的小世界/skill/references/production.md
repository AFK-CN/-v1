# 生产机制

## 主链

`具体困扰、目标肤态或使用场景 -> 可观察结果 -> 有顺序和条件的步骤或选择 -> 时间、触感或状态反馈 -> 边界`

## 选择顺序

1. 先选内容轨道：自然经验、产品决策、商业内容、平台项目、生活信任或社群互动。
2. 每条内容只设一个主任务和一个主方法；只有流程确实需要时，才组合第二个方法。
3. 动笔前确定适用条件、可替换变量、证据状态和停止条件。
4. 结构长度由“条件、动作、反馈、边界是否讲完整”决定，不预设固定分钟数。

## 四种主方法

### 1. 具体问题转成可感知结果

适合：单一肤质困扰、使用体验、阶段变化和结果复盘。

固定单元：

`当时的肤态或问题 -> 想达到的可观察状态 -> 当前或前后证据 -> 实际过程 -> 不适用边界`

可变槽位：肤质、问题、场景、目标状态、过程、观察证据。

完成标准：结果必须能被感知或观察，例如触感、紧绷感、泛红状态、上妆表现；不能把个人变化写成人人有效的功效。

### 2. 分步顺序与条件化执行

适合：护理流程、搭配顺序、阶段调整和问题处理。

固定单元：

`什么情况下适用 -> 按顺序做什么 -> 多久或多频繁 -> 观察什么 -> 什么时候调整或停止`

可变槽位：问题、产品或动作、先后顺序、频率、反馈和调整方式。

完成标准：每一步承担不同作用；读者知道为什么这样排、观察什么，以及什么时候不能继续。

### 3. 时间刻度与状态反馈

适合：连续记录、恢复过程、阶段跟练和真实使用史。

固定单元：

`起始状态 -> 时间节点 -> 当时采取的动作 -> 状态反馈 -> 下一步调整或停止`

可变槽位：周期、状态、动作、反馈和调整。

完成标准：时间是观察坐标，不是见效承诺；变化和没有变化都可以成为反馈。

### 4. 清单转成决策分流

适合：多产品对比、空瓶、好物分享、预算选择和场景清单。

固定单元：

`共同问题 -> 按肤质、问题、预算或条件分支 -> 每个选项解决什么 -> 谁或什么情况下不用 -> 最后的选择建议`

可变槽位：产品、分支条件、使用场景、预算和排除项。

完成标准：读完能做选择，不是把一组产品和形容词排列出来。

## 共同机制

- 张力：不是制造焦虑，而是让读者尽快判断“我属于哪种情况、现在发生了什么、下一步该怎么选”。
- 信任：来自真实经历、触感、时间和状态反馈，也来自明确写出翻车、无效、不适用和停止条件。
- 理解：用条件和步骤解释选择，不用百科成分课代替真实使用过程。
- 利他：读者最终能完成四件事中的至少一件——做选择、开始尝试、观察反馈、及时停止。
- 长度：讲完任务所需的条件、步骤、反馈和边界即可；不能为了短而删掉关键条件，也不能为了长重复同义句。

## 内容轨道

- 自然经验：优先使用前三种方法，保留真实过程、状态变化、失败和判停点。
- 产品决策：优先使用“清单转决策分流”，按肤质、问题、预算或使用条件分支；产品事实和个人感受分别标明。
- 商业内容：先完成用户任务，再承接产品；品牌、功效、价格和购买利益都需要独立证据，不能由账号语气代替事实核验。
- 生活信任：写具体生活事件、选择和感受，不强行回到护肤方法，也不虚构个人经历。
- 社群互动：围绕读者真实问题续讲，问题来源不明时不能伪装成粉丝提问。
- 平台项目：先确认项目机制、发布任务、素材要求和权益边界，再决定使用哪种表达结构。

默认交付包括目标人群、当前状态、问题、标题、正文、话题、视觉开场、主方法、证据参考和经验边界。

内部还需保留：轨道、主方法、适用条件、固定单元、可变槽位、证据状态、观察点和停止条件，方便复盘与多卡验证。
