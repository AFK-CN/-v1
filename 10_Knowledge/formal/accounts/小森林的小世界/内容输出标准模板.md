# 小森林的小世界内容输出标准模板

账号 Skill 版本：1.4

权威来源：`skill/references/production.md` 与 `skill/references/publishing-copy.md`。每条只选一个主模板；固定单元不能删，可变槽位必须来自本次真实素材。模板完成后另写一个受证据支持的标题承诺，并只添加正文和视觉已覆盖的话题。

## 模板一：具体问题转成可感知结果

```text
目标读者：【肤质/当前状态/生活场景】
具体问题：【不要写笼统“皮肤不好”】

开场：我当时最明显的状态是【可观察状态】，不是泛泛的“状态差”。
1. 当时肤态或问题：发生在什么时间和场景？
2. 想达到的状态：触感、紧绷、泛红或上妆表现希望发生什么变化？
3. 当前证据：图片、视频、记录或个人感受分别是什么？
4. 实际过程：按什么顺序做了什么？
5. 结果与反馈：哪些变化能观察，哪些没有变化？
6. 边界：这只是何种条件下的个人经验，谁不应照搬？
```

完成门：结果可被感知或观察，没有写成人人有效的功效。

## 模板二：分步顺序与条件化执行

```text
适用情况：【什么状态下才使用】
不适用情况：【先排除什么】

第一步：【动作】——为什么先做，观察什么？
第二步：【动作】——与第一步承担什么不同作用？
第三步：【动作】——多久或多频繁？

反馈判断：出现【状态 A】可以继续；出现【状态 B】需要调整。
停止条件：出现【不适/持续刺激/异常反应】就停止，并在需要时寻求专业帮助。
```

完成门：读者知道顺序、原因、观察点和何时不能继续。

## 模板三：时间刻度与状态反馈

```text
起始状态：【时间点 + 可观察状态】
节点一：【时间】做了什么，状态有什么变化或没有变化？
节点二：【时间】根据什么反馈继续或调整？
节点三：【时间】当前状态和起点相比怎样？
下一步：为什么继续、减少、替换或停止？
边界：时间只是本次观察坐标，不承诺别人同周期见效。
```

完成门：每个时间节点都有动作和反馈，不把时间线写成见效承诺。

## 模板四：清单转成决策分流

```text
共同问题：【这些产品共同解决什么选择难题】

如果你是【条件 A】：优先看【选项 A】，因为它解决【任务】；【情况】不选。
如果你是【条件 B】：优先看【选项 B】，观察【反馈】；【情况】停止。
如果预算/场景是【条件 C】：选择【选项 C】，舍弃什么？

个人感受：【明确标注】
可核验事实：【注明来源】
商业主张：【有独立证据才写】
最后选择：先根据【关键条件】排除，再在剩余选项中决定。
```

完成门：读者能做选择，不是产品和形容词的排列。

## 商业内容附加模板

```text
用户真实任务：【先解决什么问题】
自然内容结构：【四个主模板之一】
产品进入点：【在哪个真实动作或选择节点出现】
产品角色：【帮助完成什么任务】
事实证据：【品牌/功效/价格/权益来源】
经验边界：【个人感受与商业主张如何分开】
```

## 统一发布包

- 目标人群、当前状态和具体问题。
- 标题：一个任务或选择，不拼多个功效。
- 视觉开场：能支持当前肤态、过程或结果的真实素材。
- 正文：按所选模板写完整条件、动作、反馈和边界。
- 话题：服务检索，不反向决定产品结论。
- 内部记录：轨道、主方法、适用条件、固定单元、可变槽位、证据状态、观察点和停止条件。
