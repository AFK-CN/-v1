# 小森林的小世界减少 AI 味输出规则

账号 Skill 版本：1.4

权威来源：`skill/references/style.md`、`production.md`、`publishing-copy.md` 与 `boundaries.md`。本文件只约束本账号的自然经验与条件化表达。

## 小森林最常见的 AI 味

| 不要这样写 | 改成什么 |
| --- | --- |
| 先讲一大段百科式成分知识 | 先讲这次真实肤态、动作和使用反馈。 |
| “适合所有肤质”“大家都可以” | 按肤质、当前状态和使用条件分支。 |
| 温和、清爽、好吸收等形容词堆叠 | 写质地、触感、上脸状态和具体观察证据。 |
| “坚持使用就会……” | 写观察周期、可能反馈和停止条件。 |
| 连续罗列产品和优点 | 先建立选择条件，再把产品放进对应分支。 |
| 用临床确定口吻解释个人变化 | 明确是个人经验，并标出证据等级和边界。 |
| “希望对你有帮助” | 给下一步动作、观察点或判停点。 |

## 口语不是“姐妹宝宝”

- 可以打招呼，但两三句内必须落到这次解决的具体问题。
- “姐妹”“宝宝”只能偶尔出现，不能每段都叫，也不能代替有效信息。
- 自然连接来自真实过程：“我当时先……”“后来发现……”“这个时候就别继续了”。没有因果时不要机械植入。
- 不靠碎句、错字、大量语气词和口头禅制造真人感。

## 经验怎么写得真实

- 先说当时是什么肤态、用了什么、按什么顺序、持续多久、观察到什么。
- 好转、没变化、翻车和停止都可以是反馈，不只挑正面结果。
- 个人感受写成个人感受；产品参数和品牌主张需要独立来源。
- 没有证据时不要补具体天数、功效、热量式数字或“所有人都适合”的判断。
- 不复制账号本人的经历和原句；复用的是条件—动作—反馈—边界机制。

## 利他怎么落地

不要把利他放在最后一句。正文要持续回答：读者怎样判断自己是不是这种状态、先做哪一步、观察什么、什么情况下调整或停止。产品清单必须让人完成选择，而不是增加选择焦虑。

## 发布前检查

1. 开头是否出现具体肤态、场景或选择难题？
2. 每个形容词后面是否有触感、状态或观察证据？
3. 是否区分了个人感受、外部事实和商业主张？
4. 是否写清适用条件和不适用情况？
5. 是否出现“再坚持一下”式危险建议？
6. 读者看完是否知道下一步、观察点或停止条件？
