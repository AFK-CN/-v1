# 姜胡说内容输出标准模板

账号 Skill 版本：1.4

权威来源：`skill/references/production.md` 与 `skill/references/publishing-copy.md`。先选一个模板，再用本题真实材料填写；固定单元不能删，可变槽位不能从旧稿换词复制。模板完成后另写一个具体标题承诺、由正文兑现，并只添加正文实际覆盖的话题。

## 模板一：人物或项目推进

适用：真实人物、创业项目、内容实践、技能训练或长期行动。

```text
黄金三秒：在【具体时刻/处境】，谁正在处理【具体问题】，出现了什么意外卡点？

1. 原处境：人物是谁，当时有什么目标和约束？
2. 第一个具体行动：他实际做了什么，不写抽象努力。
3. 阻力或失败：哪一步没有按预期发生？
4. 调整或转折：删了什么、换了什么、重新怎么做？
5. 可观察反馈：用户、结果、过程或状态发生了什么变化？
6. 一个判断：这段过程真正说明了哪一个机制？
7. 受众下一步：如果你处在【条件】，先做【动作】；做到【标准】再进入下一步；出现【情况】就停。
```

完成门：删除观点后仍能看懂事情怎么发生；观点能由过程推出。

## 模板二：可核验结果复盘

```text
黄金三秒：先给【可核验结果】，同时说明它不代表什么。

1. 起点与约束：开始时有什么条件、资源和限制？
2. 关键动作：真正改变过程的两三个动作是什么？
3. 卡点：哪一步失败、停滞或与预期不同？
4. 修正：根据什么反馈做了什么调整？
5. 证据：哪些结果可以回查？哪些仍没有解决？
6. 迁移判断：别人可以复用的是哪条判断，不是照抄哪个结果？
7. 边界：在哪些条件下，这个判断可能不成立？
```

完成门：结果、动作和因果能对应，没有把相关性写成必然性。

## 模板三：受众追问续讲

```text
问题来源：【真实评论/前序内容/用户给定问题】
具体追问：【原问题的准确含义】

1. 误解发生在哪一步？
2. 用一个新案例把误解展开。
3. 错误做法通常会导致什么具体后果？
4. 正确的第一步是什么？
5. 做到什么算完成，什么情况下不适用？
6. 留下一个从本题自然产生的下一问。
```

完成门：脱离上一条也能独立看懂，不是旧观点改写。

## 模板四：生活场景与案例组

```text
共同问题：【观众现实中会遇到的具体问题】

场景一：谁在什么地方做了什么，产生什么后果？
场景二：换一个关系或约束，动作和后果有什么不同？
共同机制：两个案例真正共享的关系是什么？
关键差异：什么条件一变，结论就会变化？
受众选择：你属于【条件 A】先做什么；属于【条件 B】不要照搬什么。
```

完成门：每个案例都增加新证据或新边界，不是同一结论重复三次。

## 模板五：复杂问题与模型案例

```text
具体问题：【不能只写大方向】
反常识判断：【一句，但下一段必须验证】

1. 案例或变量 A：发生了什么？
2. 案例或变量 B：哪里相同，哪里不同？
3. 关键关系：真正影响结果的是哪两个或三个变量？
4. 最小模型：用一句关系式、对照或结构解释，不堆术语。
5. 回看案例：模型如何改变了对 A、B 的解释？
6. 验证动作：观众如何用一次小行动检验？
7. 失效边界：什么条件下模型不能使用？
```

完成门：模型能产生新判断或行动，不是给常识换一个高级名字。

## 统一发布包

- 选题：受众 + 具体问题 + 新变量。
- 发布标题：承诺一个明确问题或判断，不拼接多个爆点。
- 发布文案：补充正文信息，不重复标题。
- 话题标签：服务检索，不反向决定内容方法。
- 黄金三秒：问题、结果、场景或反常识判断之一。
- 完整正文：按所选模板闭环。
- 互动收尾：邀请回答与本题相关的具体问题，不泛泛求互动。
- 内部溯源：主方法、发动机、固定单元、可变槽位、完成门和证据来源。
