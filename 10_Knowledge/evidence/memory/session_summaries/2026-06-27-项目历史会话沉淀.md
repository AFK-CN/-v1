# 项目历史会话沉淀

状态：approved  
用途：汇总当前知识库项目多次会话中已经验证、未来会复用的项目记忆。  
边界：本文件只沉淀知识库项目相关记忆；不包含其他项目、账号密钥、token、密码或本机私有凭证。

## 1. 索引分层与默认入口

知识库索引必须分层：全量机器索引、轻量摘要入口、正式知识索引、候选资产索引、blocked 边界索引、任务入口索引和账号索引各自承担不同职责。  
默认调用不能读取全量 `knowledge_index.json`，应先读轻量摘要、任务入口和账号索引。  
blocked 边界必须机器可读，且不能展开原始资料目录。

## 2. 总控入口与运行保障

`@知识库 + 需求` 是默认自然语言入口，同时保留“我要出选题 / 我要写文案 / 我要复盘 / 我要入库 / 我要查账号 / 我要学习账号 / 我要看状态”等固定高级入口。  
需求不清晰时，系统最多问 3 个关键问题，不能直接瞎生成。  
运行保障不只是文件存在，还要检查路由、输出契约、dashboard、registry、Skill 包、索引和测试是否一致。

## 3. 姜胡说账号级内容生产入口

姜胡说内容生产应优先走账号中心，而不是直接从方向目录开始。  
稳定读取顺序是：账号索引、内容生产使用说明、减少 AI 味输出规则、内容输出标准模板，再按方向读取方法论、粗扫内容、卡片和逐字稿。  
账号通用模板和减少 AI 味规则属于账号层，不属于单个“赚钱”方向。  
选题和文案输出必须保留对标知识库内容、来源层级、source_id 或原抖音链接等溯源字段。

## 4. 内容粗扫与正式入库

粗扫引擎应 profile 化、配置化，不能硬编码到一个账号。  
先看代码产物、manifest、报告和验证结果，不要让 Codex 手动扫原始数据。  
姜胡说粗扫曾验证出 573 个唯一内容、127 个深学目标、446 个非深学项，后续正式状态必须以当前正式目录、审计和索引为准。  
旧 handoff 或计划文档可能滞后，不能覆盖当前正式入库状态。

## 5. 视频学习闭环

视频学习主链路是 `scan -> select -> learn -> status`。  
长任务要通过 `.status.json`、heartbeat、日志、manifest 和队列状态判断，不优先依赖 `ps`。  
下载和视频分析任务应防睡眠，媒体存在时要用 `ffprobe` 或项目 helper 验证可读性。  
流程跑通不等于 1.0，只有 ingest、rollback、目录契约都独立验证后才算完整版本。

## 6. 架构图与可视化交付

涉及架构图、运行逻辑图时，优先产出可维护文件，例如 Mermaid 和 SVG，而不是只给文字解释。  
图应表达真实运行链路：原始资料只读、字段标准化、去重、质量评分、入库决策、内容生产、反馈复盘、Skill 进化。  
如果缺 Graphviz，不应卡住任务，Mermaid 或手写 SVG 是可接受 fallback。

## 7. 物理迁移、记忆与智能体系统

旧系统目录已物理迁移到 `00_System/shareable/`，运行态留在 `00_System/runtime/`。  
系统层可分享，运行状态和本机私有内容不可分享。  
记忆系统采用“系统规则集中、产物分层、入口集中”的结构。  
智能体功能表可同步，真实登录状态和凭证位置提示只在本机私有层。
