# Skill 提案：JSON 入库 v1

状态：proposal，待你确认后才能进入 active。

## 触发原因

你大概率会定期给 JSON 文件，且爬虫数据可能重复、无效、字段类型不统一。

## 新规则

每次新增 JSON：

1. 不修改原始文件。
2. 识别平台和数据类型。
3. 统计总数、字段、缺失值、重复 ID。
4. 指标字段统一转数字。
5. 执行 ID 去重和文本指纹去重。
6. 输出 keep/review/archive/discard 决策。
7. 只把代表记录和方法论证据写入正式知识库。

## 风险

- 近似去重可能误判相似内容。
- 只按指标可能放大爆款偏差。

## 回滚方式

保留原始文件不动；若清洗结果有误，只重建派生产物。
