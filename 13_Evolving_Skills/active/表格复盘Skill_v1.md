# Skill：表格复盘 v1

状态：active，已由你确认生效。

## 适用场景

你提供小红书、抖音或其他平台导出的表格，或者自己整理的发布数据表。

## 工作规则

处理表格时按以下顺序：

1. 识别平台、时间范围、账号或项目。
2. 读取字段名，保留原始字段解释。
3. 找到核心指标：曝光、播放、点赞、收藏、评论、分享、转粉、完播、点击。
4. 按平台分开排序，不跨平台硬比。
5. 输出最佳内容、最差内容、异常内容。
6. 反推已验证/失效的方法论。

## 输出格式

```yaml
platform:
date_range:
rows:
columns:
best_items:
worst_items:
method_updates:
topic_updates:
uncertain_columns:
```

## 风险控制

- 不同平台导出字段含义不同，不能混用定义。
- 表格缺少内容文本时，必须回查内容标题或原始案例。
- 不能只看数字，必须结合内容结构、选题、平台和发布时间判断。
