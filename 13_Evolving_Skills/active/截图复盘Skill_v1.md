# Skill：截图复盘 v1

状态：active，已由你确认生效。

## 适用场景

你提供小红书、抖音或其他平台的后台截图、单条内容数据截图、评论截图。

## 工作规则

读取截图时按以下顺序：

1. 先识别平台和页面类型。
2. 只记录截图中明确可见的指标。
3. 不猜测被遮挡或看不清的数值。
4. 标注不确定字段。
5. 将截图指标与对应内容 ID、标题、发布时间绑定。
6. 进入周复盘时，优先比较同平台同周期的相对表现。

## 输出格式

```yaml
platform:
page_type:
content_id:
visible_metrics:
uncertain_metrics:
performance_signal:
next_review_action:
```

## 风险控制

- 截图清晰度不足时，必须标注不确定，不能强行读数。
- 平台页面字段变化时，需要提出 Skill 更新建议。
- 截图只作为表现证据，不能单独决定方法论长期有效。
