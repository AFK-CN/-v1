# 规则权威源

本文件只说明“哪类规则由哪里负责”，避免同一规则被分散写在多个 Markdown 文件里并逐渐不同步。

## 权威分工

- `AGENTS.md`：项目启动、默认不扫描、外部工具安全边界。
- `14_KB_System/index/controller_routes.json`：用户意图路由、最低输入、读取入口、输出契约和写入边界。
- `14_KB_System/config/layer_map.json`：系统层、知识层、用户层、本机私有层、临时层的目录映射、分享边界、默认阻断目录、候选资产根和正式知识根。
- `tools/kb/schemas.py`：状态枚举、默认阻断目录、兼容结构分类和 layer map 读取逻辑。
- `14_KB_System/config/skill_contract.json`：中英文 Skill 包共享的启动读取顺序、默认禁止目录和触发入口。
- `tools/kb/runtime.py`：Initialization Lifecycle、health-gate、doctor、repair、lock、健康凭证和 runtime 分层。
- `14_KB_System/config/search_terms.json`：轻量检索同义词、方向词和查询扩展。

## 禁止重复维护

不要在 Markdown 文档里再维护一份并行规则清单。说明文档只能引用上述权威源；如果规则要改，先改权威源，再由生成器或索引刷新引用产物。

## Agent 定义边界

`controller_routes.json` 里的 Agent 是同一次 AI 调用中的逻辑职责提示，不是独立进程、权限隔离或安全边界。真实边界必须由代码、schema、索引、输出契约和 runtime gate 执行。
