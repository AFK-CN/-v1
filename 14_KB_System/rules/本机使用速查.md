# 本机使用速查

核心路径：

```text
/Users/lao_wu/codexAI/知识库
```

## 新对话最简单用法

优先直接使用稳定入口：

```text
@知识库 + 你的需求
```

例如：

```text
我要出选题 按照{账号/风格}，给我出 20 个{平台/方向}选题。
```

如果当前界面不识别中文 Skill，使用兼容入口：

```text
knowledge-base + 你的需求
```

日常入口先运行共享凭证检查：

```bash
.venv/bin/python -m tools.kb.cli --root . health-gate
```

`requires_init` 时运行 `kb init`；`requires_doctor` 时运行 `kb doctor`，仅 repairable 时运行 `kb repair`。health-gate 不遍历正式知识文件。

如果 Skill 入口失效，再回退到读取唯一入口文件：

```text
请读取 /Users/lao_wu/codexAI/知识库/知识库入口.md，并按里面的规则使用知识库。
```

如果是在本项目目录里，也可以说：

```text
请使用 /Users/lao_wu/codexAI/知识库 作为当前知识库。
先读 知识库入口.md。
这次只围绕本机知识库工作。
```

把表格放进 `00_Inbox`，然后说：

```text
请按表格复盘 Skill 处理这个表格。
先识别字段和时间范围，再复盘表现好的内容、表现差的内容、需要更新的方法论。
```

## 我要出选题

```text
我要出选题 按照{账号/风格/方向}，给我生成 20 个{平台}选题，每个说明受众痛点、钩子角度、核心观点、对标知识库内容和原链接。
```

需要在本机先验证“用户原话会命中哪个路由、读取哪些账号知识和输出契约”时，可运行：

```bash
.venv/bin/python -m tools.kb.cli --root . resolve-call --text "@知识库 按姜胡说的方式出2个赚钱选题"
```

该命令只生成确定性调用计划和候选检索结果，不调用模型、不生成最终文案、不写正式知识。

## 我要写内容

```text
我要写文案 把这个选题写成{平台/形式}，输出黄金3s、完整文案、互动收尾和证据来源。
```

## 需求不清晰时

如果只说“我要出选题”“我要写文案”“我要复盘”，系统应该先反问最多 3 个关键问题，例如方向、平台、数量、资料来源或复盘目标；不要直接瞎生成。

## 我要周复盘

```text
请按周复盘模板复盘本周数据。
输入包括我给的 JSON、截图、表格和口头反馈。
输出：有效方法论、失效方法论、下周选题、需要我补充的数据。
```

## 最重要的规则

- 原始文件不修改。
- 子库新增先问你。
- Skill 修改先提案，不能直接覆盖。
- 无效信息不进正式知识库。
- 内容生成结果不能直接反写正式知识。
- 原始 JSON 单文件损坏时继续处理其他文件，并在结果和报告中列出失败文件。
- repair 只能重建可再生产物和标记 stale，不能恢复或重跑任务。
