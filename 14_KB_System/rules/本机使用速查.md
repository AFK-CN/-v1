## 新对话最简单用法

不要直接输入 `@知识库` 当作命令。Codex 里的 `@` 更像文件选择器，会弹出很多文件，容易选乱。

最稳的方式是让新对话读取唯一入口文件：

```text
请读取 /Users/lao_wu/codexAI/知识库/知识库入口.md，并按里面的规则使用知识库。
```

如果是在本项目目录里，也可以说：

```text
请使用 /Users/lao_wu/codexAI/知识库 作为当前知识库。
先读 知识库入口.md。
这次只围绕本机知识库工作。
```

## 我给 JSON

把 JSON 放到：

```text
/Users/lao_wu/codexAI/知识库/00_Inbox
```

然后说：

```text
我放了新的 JSON，请按本机知识库规则处理。
原始文件不要修改。
先去重和清洗，再告诉我哪些能进知识库、哪些要归档、是否需要新增子库。
```

## 我给截图

直接发截图，然后说：

```text
请按截图复盘 Skill 读取这张图。
只记录看得清的指标，看不清的不要猜。
判断它对方法论、选题、周复盘有什么影响。
```

## 我给表格

把表格放进 `00_Inbox`，然后说：

```text
请按表格复盘 Skill 处理这个表格。
先识别字段和时间范围，再复盘表现好的内容、表现差的内容、需要更新的方法论。
```

## 我要出选题

```text
调用主知识库和知识成长/自媒体方法论子库。
给我生成 20 个小红书/抖音选题，每个说明人群、痛点、爆点、平台形式、参考方法论。
```

## 我要写内容

```text
调用知识库，把这个选题分别写成小红书图文和抖音口播。
要求说明两个平台为什么这样改。
```

## 我要周复盘

```text
请按周复盘模板复盘本周数据。
输入包括我给的 JSON、截图、表格和口头反馈。
输出：有效方法论、失效方法论、下周选题、需要我补充的数据。
```
