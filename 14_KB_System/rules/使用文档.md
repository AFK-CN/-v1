# 知识库使用文档

这份文档解决两个问题：

1. 你在本项目新的对话框里，如何让 AI 正确使用这个知识库。
2. 你在其他项目里，如何调用这个知识库。

## 一、本项目新对话怎么用

如果新开一个 Codex 对话，先告诉 AI：

```text
请使用 /Users/lao_wu/codexAI/知识库 作为当前知识库。
先阅读 知识库入口.md、README.md、14_KB_System/index/task_entry_index.md。
默认按索引按需调用，禁止全盘扫库，禁止展开扫描 数据/。
如果涉及自媒体创作，再按任务读取相关目录。
```

如果你要让它处理新 JSON：

```text
我放了新的 JSON 到 /Users/lao_wu/codexAI/知识库/00_Inbox。
请按 JSON入库Skill_v1、JSON入库清洗规则、去重规则处理。
原始文件不要修改。
不要扫描 数据/ 目录。
输出数据盘点、去重报告、可入库内容、是否需要新增子库。
```

如果你要让它看截图复盘：

```text
这是平台数据截图。
请按 截图复盘Skill_v1 读取，只记录截图中明确可见的指标。
不确定的字段请标注，不要猜。
然后判断这些反馈对方法论、选题库、用户偏好是否有更新。
```

如果你要让它看表格复盘：

```text
这是平台导出的数据表。
请按 表格复盘Skill_v1 处理。
先识别字段和时间范围，再按平台分别复盘，不要跨平台硬比。
输出最佳内容、最差内容、方法论更新、下周选题建议。
```

如果你要直接出内容：

```text
调用主知识库 + 知识成长/自媒体方法论子库。
请给我生成 10 个抖音选题，每个包含：人群、痛点、开头强观点、脚本结构、参考方法论。
```

```text
调用主知识库。
请把这个选题分别改成小红书图文和抖音口播，说明两端平台差异。
```

如果你要做周复盘：

```text
请按 /Users/lao_wu/codexAI/知识库/10_Weekly_Review/周复盘模板.md 做本周复盘。
输入包括本周新增 JSON、截图、表格和我的口头反馈。
复盘后更新方法论、选题库、用户偏好，并提出 Skill 更新提案。
```

## 三、其他项目怎么使用

其他项目不要复制整套知识库，推荐只写一个调用说明文件。

在其他项目根目录创建或让 AI 创建：

```text
KNOWLEDGE_USE.md
```

内容可以这样写：

```markdown
# 本项目调用知识库规则

知识库路径：/Users/lao_wu/codexAI/知识库

本项目允许调用：

- `知识库入口.md`
- `14_KB_System/index/`
- 主知识库中与任务匹配的正式目录
- 06_Sub_KB/知识成长自媒体方法论
- 02_Viral_Methods
- 03_Topic_Ideas
- 04_Platform_Knowledge
- 08_Content_Factory
- 13_Evolving_Skills/active

本项目默认禁止调用：

- 数据/ 原始爬虫数据
- 00_Inbox/ 原始输入
- 99_Archive/ 低价值归档
- 13_Evolving_Skills/proposals 未确认提案
- 14_KB_System/assets/ 候选资产，除非任务是审核候选

使用要求：

- 先读 `14_KB_System/index/task_entry_index.md`，再按任务读取少量对应目录。
- 禁止全盘扫库、禁止随便找内容、禁止默认读取 `数据/`。
- 输出内容必须说明调用了哪个子库或方法论。
- 不直接复制原始案例大段文本。
- 如发现适合本项目的新规则，只能提出更新建议，不能直接修改主知识库。
```

然后在其他项目的新对话里说：

```text
请按本项目的 KNOWLEDGE_USE.md 调用 /Users/lao_wu/codexAI/知识库。
这次任务只使用主知识库和 知识成长/自媒体方法论 子库。
```

## 四、常用指令

### 生成选题

```text
基于主知识库和知识成长/自媒体方法论子库，给我生成 20 个小红书/抖音选题。
要求每个选题包含：平台、人群、痛点、爆点、内容形式、参考方法论、为什么值得做。
```

### 生成脚本

```text
调用抖音爆款方法论 v1，把这个选题写成 60 秒口播脚本。
要求：强观点开头、3 段结构、结尾有可复述金句。
```

### 生成小红书图文

```text
调用小红书爆款方法论 v1，把这个主题写成小红书图文。
要求：标题 10 个、封面文案 5 个、正文结构、收藏理由、评论区提问。
```

### 复盘内容表现

```text
请读取我给的截图/表格，按周复盘模板复盘。
判断哪些方法论被验证，哪些要降权，下周应该做哪些选题。
```

### 更新知识库

```text
请根据这次反馈更新知识库。
注意：原始资料不修改；子库新增或 Skill 修改先给我确认。
```
