# 选题生成规则

选题不是标题库。选题必须包含“谁在什么场景下，为什么需要这个内容，以及平台上如何表达”。

## 选题卡片格式

```yaml
topic_id:
platform:
领域:
人群:
场景:
痛点:
内容承诺:
爆点:
形式:
参考方法:
可生成标题:
正文/脚本方向:
证据:
优先级:
状态: candidate | ready | used | retired
```

## 生成方式

选题来源：

- 高表现案例反推。
- 评论区高赞需求。
- 用户反馈。
- 周复盘发现。
- 必要时联网检索热词。

## 组合规则

主知识库可以跨领域组合，例如：

- 美食方法论 + 自媒体表达：把减脂餐做成“普通人可执行系统”。
- 评论洞察 + 选题库：从评论中找用户原话，再生成标题。
- 平台差异 + 同一选题：同题分别改写成小红书图文和抖音短视频。
