# 用户层与生产记忆规范

系统层定义用户层结构、初始化、迁移和验证规则；用户层保存本机账号 Skill 注册、生产记录、反馈与机器配置。新电脑先运行 `skill-install` 绑定 KB root，再运行 `user-init` 建立相同骨架，不复制旧电脑的真实数据。

## 目录

- `20_User/config/`：账号 Skill 注册表、账号粗学 profile 和用户默认行为，可按用户选择同步。
- `20_User/data/`：本机 SQLite 生产记忆，不进入系统分享包。
- `20_User/feedback/`：截图、表格和人工反馈。
- `20_User/private/`：私有内容，默认阻断。
- `20_User/local/`：NAS、机器路径和环境配置，禁止分享。

## 数据库调用边界

模型从不读取完整数据库。代码在库内完成结构化查重和聚合：

- 正常通过只返回数量和通过状态。
- 可能重复只返回最多 5 条冲突摘要及相似字段。
- 复盘只返回一个 `content_id` 的上下文。
- 批量候选一次查询，不逐个打开数据库。

这使生产记忆随数据增长仍保持固定的小上下文成本。
