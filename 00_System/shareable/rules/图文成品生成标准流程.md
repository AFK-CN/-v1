# 图文成品生成标准流程

用途：把图文成品生成放在现有内容生产链路中。它不是新的知识库，不是新的账号中心，也不是和出选题并列的入口；它是选题确认后的成品分支。

## 流程位置

```text
出选题
-> 用户确认选题
-> 选择成品形式
   -> 视频：走视频脚本/口播生产
   -> 图文：走图文成品生成
-> 成品验收
-> 发布
-> 发布后复盘
```

## 输入条件

进入图文成品生成前，至少要有：

- 已确认的选题或选题编号。
- 目标账号或账号风格来源。
- 平台，默认可按小红书图文处理。
- 期望图片张数；未指定时先按 5-7 张规划。
- 是否允许调用 image2 生图；未确认前只输出图文脚本包。

如果只有“我要生成图文”，但没有选题，先回到出选题流程。

## 读取顺序

1. `10_Knowledge/evidence/index/account_knowledge_index.md`：确认账号中心位置。
2. `{账号}/内容生产使用说明.md`：确认正式内容生产读取顺序。
3. `{账号}/减少AI味输出规则.md`：确认账号表达禁区。
4. `{账号}/内容输出标准模板.md`：确认通用交付字段。
5. `directions/{方向}/方向方法论总结.md`：确认方向方法。
6. `directions/{方向}/粗扫内容和选题.md`、`directions/{方向}/cards/*.md`：按需读取选题和证据。
7. 已审核通过的图文学习结果：只用于调用账号的封面策略、分图结构、视觉风格、色系和排版习惯。

候选图文学习卡只能作为候选证据，必须标注来源层级；不能当成正式账号知识。

## 执行步骤

1. 选题确认：确认本次图文围绕哪个选题生成。
2. 风格调用：读取账号图文学习结果，提取封面、分图、色系、排版、人物/场景呈现方式。
3. 图文脚本包：先输出可审核方案，不立即生图。
4. 人工确认：用户确认选题方向、分图节奏、封面标题和视觉方向。
5. image2 生图：确认后再根据图文脚本包和账号视觉风格调用 image2。
6. 成品验收：检查文字、画面、风格、连贯性和平台适配。
7. 发布后复盘：只把表现结果进入复盘；不直接反写正式知识。

## 图文脚本包字段

- 选题
- 账号/方向
- 平台
- 图片张数
- 封面标题
- 封面画面描述
- 分图结构：每张图的标题、正文短句、画面重点、设计提示
- 发布标题
- 发布正文
- 话题标签
- 互动收尾
- 借鉴学习卡或证据来源
- 来源层级
- 证据边界
- image2 生图提示词草案

## 生图验收字段

- image2 生成状态
- 生成图片清单
- 每张图对应的分图脚本
- 文字清晰度
- 账号风格贴合度
- 封面点击欲
- 分图连贯性
- 需重生成图片
- 发布前风险

## 禁止动作

- 不在选题未确认时直接生图。
- 不把图文生成做成独立知识库或独立账号中心。
- 不把候选图文学习卡当成正式知识。
- 不让 image2 替代账号学习；image2 只执行生图。
- 不跳过图文脚本包审核直接批量生图。
- 不把生图结果直接写入正式知识；发布后复盘通过再考虑沉淀规则。
