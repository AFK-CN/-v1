# 输出契约

机器权威源是 `00_System/shareable/config/output_contracts.json`。所有任务必须说明命中路由、读取层级、正式/候选边界和写入结果。

## 内容处理

输出资料范围、媒介分支、清洗统计、完整粗学与选题池、深学计划、证据状态和阻塞项。不得修改原始资料或写正式账号中心。

## 账号学习

输出 workflow、阶段状态、统一学习卡、流派观察、三重验证、拒绝项、RIA++ 方法、压力测试、生产交接和账号 Skill 候选。用户审核前不可调用。

## 出选题

输出账号 Skill 与版本、结构化选题字段、查重状态、真实新变量和 `topic_id`。查重只接收代码返回的少量冲突摘要，不读取完整数据库。

## 写内容

输出账号 Skill 与版本、`topic_id`、`content_id`、完整发布包、内部溯源和生产登记状态。不得编造原句、经历、数据或外部结果。

## 内容复盘

输出 `content_id`、选题、账号 Skill 版本、反馈证据、问题诊断、信号级别和下一步。只能提出补学或更新提案，不自动修改 Skill。

## 用户层与系统审计

用户层初始化输出目录、账号 Skill 注册表、生产数据库、迁移和验证结果。系统审计输出三套系统 Skill、用户层、账号 Skill、生产记忆、索引、边界、清理和测试结果。
