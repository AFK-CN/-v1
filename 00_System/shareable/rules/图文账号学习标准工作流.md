# 图文账号学习标准工作流

本规则定义账号学习中的 `image_text` 媒介分支。它只补齐图文学习路径，不改变现有知识库架构；正式知识仍汇入账号中心，图文学习产物先进入候选区和审核清单。

## 定位

- 图文学习是账号学习 route 的一个媒介分支，和视频学习并行。
- 视频学习继续走 `scan -> select -> learn -> status`。
- 图文学习走 `ingest -> structure -> scan -> select -> learn -> status`。
- 图文原始图片、截图和图文包只读；结构化结果、报告、学习卡和审核清单不等于正式知识。
- OCR 和图片视觉特征由工具生成；image2 是 Codex 会话内看图能力，不是第三方工具。账号规律必须由 Codex 基于 OCR、视觉特征、图片本身和会话内看图结果学习，并经过学习报告、候选卡和审核。

## 存储边界

| 类型 | 建议路径 | 边界 |
| --- | --- | --- |
| 用户临时输入 | `90_Temp/scratch/image_text_learning/input/` | 临时任务输入，不作为正式知识。 |
| 结构化缓存 | `00_System/runtime/cache/image_text_learning/` | 代码生成的 OCR、图片清单、结构化 JSON 和中间结果。 |
| 状态与报告 | `00_System/runtime/state/image_text_learning/`、`00_System/runtime/reports/image_text_learning/` | 任务进度、失败项、验收报告和学习状态。 |
| 候选账号资产 | `10_Knowledge/candidates/account_assets/image_text_learning/` | 账号级候选概述、粗学池、图文结构报告。 |
| 候选学习卡 | `10_Knowledge/candidates/learning_cards/image_text_cards/` | 单篇图文深学卡，未经审核不能写入正式账号中心。 |
| 正式账号知识 | `10_Knowledge/formal/accounts/.../账号中心/{账号}/` | 只有用户确认或审核通过后才写入。 |

## 执行流程

| 步骤 | 代码要做什么 | Codex/AI 要做什么 | 必须产物 |
| --- | --- | --- | --- |
| 1. ingest | 接收用户指定的本地图片包、图文 manifest 或截图目录；登记账号、平台、source_id 和图片顺序。 | 确认资料范围和账号归属，不默认扫描原始资料目录。 | `image_text_manifest.json`、输入清单。 |
| 2. structure | 对图片生成统一结构化 JSON；用 PaddleOCR 生成文字和文本块，用 Pillow/OpenCV 生成尺寸、色系、清晰度、复杂度等客观视觉特征，并标记待 Codex image2 视觉审核。工具缺失时降级并保留缺口。 | 判断字段是否足够学习；缺图、顺序不明、OCR 低置信、待看图证据未补时标注证据不足。 | `structured_posts.jsonl`、`structure_report.md`。 |
| 3. scan | 按账号、方向、标题、正文、话题、封面文本、图片角色做粗学统计。 | 归纳发布内容层和图文结构层的初步规律，不把 Top 内容当成全量选题池。 | `账号概述.md`、`粗学与选题池.md`、`deep_learning_plan.json`。 |
| 4. select | 根据方向覆盖、热度、代表性、结构完整度选择深学图文。 | 判断是否需要补图、补标题、补正文或补 OCR。 | `selected_image_text_learning.json`。 |
| 5. learn | 为选中图文生成候选学习卡和账号级图文学习报告。 | 提炼封面策略、分图结构、标题/正文协同、视觉表达和账号风格候选结论。 | 图文深学卡、`image_text_learning_report.md`、审核清单。 |
| 6. status | 汇总完成度、失败项、证据缺口和可入库建议。 | 判断是否进入正式入库审核；不直接写正式账号中心。 | `latest_image_text_status.json`、`latest_image_text_report.md`。 |

## 审核门

- OCR 未接入、OCR 置信度低、图片缺失、图片顺序不明、Codex 看图证据未补、标题正文缺失时，只能进入候选或待补证据。
- 封面策略、分图结构、视觉风格、账号口吻和选题规律必须回到具体 `source_id` 和图片序号。
- image2 是 Codex 会话内看图能力，只能补图片转述、构图描述和视觉证据；账号学习结论仍由 Codex 在学习阶段综合生成。
- 用户确认或审核注册表通过前，不得更新正式账号中心。
- 图文学习得到的账号专属模板只能写入对应账号中心，不能写成通用系统规则。
