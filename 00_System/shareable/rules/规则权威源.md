# 规则权威源

同一规则只维护一份权威源，说明文档只做引用。

- 启动与原始资料边界：`AGENTS.md`
- 当前系统版本、升级范围与验收矩阵：`system_version.json`
- 意图路由：`00_System/shareable/index/controller_routes.json`
- 输出契约：`00_System/shareable/config/output_contracts.json`
- 系统/知识/用户分层：`00_System/shareable/config/layer_map.json`
- 知识库 Skill 入口：`00_System/shareable/config/skill_contract.json`
- 内容处理：`00_System/shareable/skills/active/content-processing/`
- 账号学习：`00_System/shareable/skills/active/account-learning/` 与 `account_learning_pipeline.json`
- 内容复盘：`00_System/shareable/skills/active/content-review/`
- 用户层：`user_layer_schema.json`
- 账号无关的基础粗学分类：`content_classification_defaults.json`；账号专属方向只能写入用户层 profile
- 正式知识混合检索与边界：`formal_retrieval.json`
- 表达资产候选的通用结构、隔离和验收门：`expression_asset_contract.json`；active 账号学习接入仍受对应 proposal 确认门约束
- 账号 Skill 包：`account_skill_contract.json`
- 正式账号目录：`10_Knowledge/formal/accounts/{账号}/ACCOUNT_SKILL_MANIFEST.json`
- 生产记忆：`production_memory_schema.json`
- 账号 Skill 注册数据：`20_User/config/account_skill_registry.json`
- 账号专属生产规则：对应账号中心的 `skill/`

`10_Knowledge/formal/accounts/` 只允许直属账号目录，不允许主题、平台或“账号中心”中间层。跨账号主题归纳只能先进入候选层，不能包裹正式账号。

`rules/` 只保留跨系统边界；内容处理、账号学习和内容复盘的专项标准必须随对应 Skill 放入 `references/`，不得在公共目录维护第二份流程。

`controller_routes.json` 中的 Agent 只是逻辑职责，不是独立进程或权限边界。真实边界由代码、schema、索引和验证器执行。
