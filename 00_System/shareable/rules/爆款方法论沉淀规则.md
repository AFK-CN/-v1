# 爆款方法论沉淀规则

爆款方法论不能只写“情绪强”“有价值”“标题好”。每条方法必须能指导下一次创作。

## 方法论卡片格式

```yaml
method_id:
platform:
适用领域:
适用人群:
适用场景:
核心机制:
内容结构:
标题结构:
正文/脚本结构:
可复用模板:
证据案例:
指标表现:
适合生成的选题:
不适合:
风险:
```

## 提炼标准

一条方法进入 `10_Knowledge/formal/methods/` 至少满足一项：

- 有高指标案例支撑。
- 在多个主题变体中重复出现。
- 评论区证明用户有强需求。
- 能稳定产出多个选题。
- 能被小红书或抖音平台改写复用。

## 平台差异

小红书优先关注：

- 收藏价值。
- 可照抄执行。
- 清单、步骤、食谱、模板。
- 生活场景和身份标签。

抖音优先关注：

- 开头冲突和价值判断。
- 强观点、强金句。
- 评论区共鸣。
- 分享价值和行动冲动。
