# 知识库系统 3.1.0

发布日期：2026-07-19
工程版本：`3.1.0`
系统版本：`3.1`

## 重点

3.1 在系统 3.0 基线上补齐表达资产学习：逐条列出和拆解发布内容、视频开头及内容过程中的钩子、金句、句式与完整结构，并把它们接入原七阶段的审计、样本验收、跨卡聚合、压力测试和候选交付。

active 入口仍只有一套七阶段工作流。新任务默认启用表达资产链；旧任务只在原 workflow_id 上经确认原地补齐，不复制工作流、不删除旧能力和旧产物。

## 边界

- 只升级系统机制，不执行真实账号学习。
- 不生成真实账号资产，不读取或修改账号中心。
- 来源原文永久不可生成。
- 候选抽象模式不可直接生产。
- 禁止跨账号补样本、合并规则或借用验收证据。
- 正式知识、原始资料、账号 Skill 和既有候选均不删除。
