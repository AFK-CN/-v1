# 知识库优化目录结构

本文件记录目标目录结构和迁移边界。当前采用渐进迁移：先让系统识别新层级，再按报告迁移旧目录。

```text
知识库/
├── 00_System/                        # 系统层：知识库底座，负责规则、代码、CLI、Skill、索引、schema
│   ├── shareable/                    # 可分享系统：未来可打包给别人复用
│   └── runtime/                      # 运行状态：不可分享，保存任务、缓存、日志、报告、健康凭证、锁
├── 10_Knowledge/                     # 知识层：系统运行后沉淀的正式知识、候选知识、证据索引
│   ├── formal/                       # 正式知识：默认可被调用
│   ├── candidates/                   # 候选知识：待审核，不能当正式知识直接调用
│   └── evidence/                     # 证据索引：来源链接、片段映射、追溯关系
├── 20_User/                          # 用户层：个人偏好、长期纠正规则、个人工作流
│   ├── syncable/                     # 可同步偏好：可跨设备或项目复用
│   └── private/                      # 用户私有：默认不分享、不外部调用
├── 80_Local/                         # 本机私有配置：路径、账号标识、NAS、私有开关、密钥引用说明
├── 90_Temp/                          # 临时层：短期输入、草稿、一次性中间文件、临时导出
├── 99_Archive/                       # 归档层：历史、废弃、低价值内容索引
└── 数据/                              # 受保护原始资料：默认不展开、不删除、不分享
```

## 分享边界

- 只允许分享 `00_System/shareable/`。
- 禁止分享 `00_System/runtime/`、`80_Local/`、`20_User/private/`、`90_Temp/`、`99_Archive/`、`数据/`。
- `10_Knowledge/` 是当前用户沉淀的知识资产，不进入系统模板包。

## 候选资产边界

候选资产属于知识层，目标位置是 `10_Knowledge/candidates/`。它们不是临时垃圾，也不能被当作正式知识直接调用。

## Skill 边界

通用系统级 Skill 属于系统层，目标位置是 `00_System/shareable/skills/`。账号专属风格、账号模板和个人偏好不写入系统级 Skill，应分别进入 `10_Knowledge/` 或 `20_User/`。
