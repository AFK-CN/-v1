# 知识库优化目录结构

```text
知识库/
├── 00_System/
│   ├── shareable/          # 可迁移系统：三套 Skill、路由、契约、代码规范和文档
│   └── runtime/            # 可再生运行状态，不分享
├── 10_Knowledge/
│   ├── formal/accounts/    # 正式账号直属目录；账号 Skill 位于 {账号}/skill/
│   ├── candidates/         # 学习候选与证据，审核前不可调用
│   └── evidence/           # 轻量索引和追溯关系
├── 20_User/
│   ├── config/             # 账号 Skill 注册、粗学 profile 与用户默认行为
│   ├── data/               # 本机生产记忆 SQLite
│   ├── feedback/           # 截图、表格和人工反馈
│   ├── private/            # 用户私有内容
│   └── local/              # NAS、机器路径和环境配置
├── 90_Temp/                # 一次性输入、草稿和导出
├── 99_Archive/             # 已退役历史
└── 数据/                   # 受保护原始资料，只读
```

## 分享边界

只分享 `00_System/shareable/` 和运行所需代码。`10_Knowledge/` 与 `20_User/` 都是当前用户的数据面；runtime、临时层、归档和原始资料也不进入系统包。

## Skill 边界

- 系统 Skill：内容处理、账号学习、内容复盘，必须保持账号无关。
- 账号 Skill：位于对应账号中心，保存该账号的生产、表达、边界与验收规则。
- 正式账号必须是 `formal/accounts/` 的直属子目录；禁止主题、平台或“账号中心”中间层。
- 用户层注册表：决定本机启用哪些账号 Skill，不跟系统模板走。
- 生产记忆：属于用户层，由代码查询；模型不读取完整数据库。
