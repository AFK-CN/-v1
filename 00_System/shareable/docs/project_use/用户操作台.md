# 知识库用户操作台

默认入口：`@知识库 + 你的需求`。兼容入口：`knowledge-base + 你的需求`。

## 三条主链

### 1. 处理资料

```text
我要处理资料：把这些链接 / SQLite / NAS / 本地资料完成下载、解析、清洗、扫描、粗学归类和深学计划。
```

由 `content-processing` 执行。下载、清洗、转写、OCR、抽帧、粗扫都保留。

### 2. 学习账号

```text
我要学习账号：学习{账号与资料范围}，按阶段给我审核，最后生成账号 Skill 候选包。
```

由 `account-learning` 执行。视频、图文、剧情、长文案使用同一主流程和不同观察适配器。用户确认后，账号 Skill 才进入对应账号中心并注册到用户层。

### 3. 使用账号 Skill 生产

```text
我要出选题：按{账号}生成{数量}个{方向/平台}选题。
我要写文案：按{账号}把这个选题写成{平台/形式}。
```

总控从 `20_User/config/account_skill_registry.json` 解析账号，只读取该账号的 `skill/SKILL.md`。生成选题前由代码批量查生产记忆，只返回少量重复冲突，不把完整数据库放进上下文。

## 复盘与强化

```text
我要复盘：复盘这条 content_id 对应的截图 / 表格 / 数据 / 人工反馈。
```

由 `content-review` 执行。它记录反馈、生成定向补学或账号 Skill 更新提案，但不会自动进化。

## 用户层和系统状态

```text
初始化用户层
同步账号Skill注册表
我要看状态
系统验收
```

新电脑先执行 `skill-install`绑定知识库根目录，再执行 `user-init`建立空白用户层、生产记忆数据库和注册表结构，不复制其他用户的数据。

## 最低输入

| 任务 | 最少需要 |
|---|---|
| 资料处理 | 账号/资料位置 + 资料范围 |
| 账号学习 | 账号 + 已处理证据范围 |
| 出选题 | 正式账号 Skill + 主题/方向 + 数量 |
| 写内容 | 正式账号 Skill + 已确认选题 + 形式 |
| 复盘 | content_id + 反馈来源 |

缺少会改变结果的关键信息时，最多追问 3 个问题；否则使用安全默认值并说明。

## 硬边界

- 默认不全盘扫库，不读取 `数据/`、`00_Inbox/`、`99_Archive/` 和用户私有目录。
- 候选学习成果不可用于生产。
- 系统 Skill 不包含账号内容；账号 Skill 不修改系统流程。
- 生产结果必须登记选题、内容和账号 Skill 版本。
- 账号 Skill 变更必须经用户确认。
