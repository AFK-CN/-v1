# 项目调用规则

其他项目通过 `@知识库 + 你的需求` 调用本知识库。中文 Skill 源包位于 `00_System/shareable/skill_packages/knowledge-base-zh/`，兼容包位于 `knowledge-base/`。

新电脑先运行 `skill-install`。全局 Skill 通过本机 `references/kb-root.json` 找到当前知识库；该定位文件属于安装结果，不进入可迁移源包。

## 固定入口

固定读取顺序来自 `skill_contract.json`。先用 `controller_routes.json` 命中路由，再读取对应系统 Skill、账号 Skill 或轻量索引；禁止全盘扫库。

## 三类调用

- 处理资料：调用 `content-processing`，保留下载、清洗、扫描和粗学流程。
- 学习账号：调用 `account-learning`，只在候选区工作，审核后生成账号 Skill。
- 生产内容：通过用户层注册表解析账号 Skill，并由代码执行生产记忆查重和登记。
- 复盘内容：调用 `content-review`，只读取一个 `content_id` 的必要上下文。

## 默认禁止

不读取 `数据/`、`00_Inbox/`、`99_Archive/`、用户数据、用户反馈、私有内容、本机配置、runtime 和未确认候选。账号 Skill 只能使用对应账号的正式知识，不能把一个账号的规则迁移到另一个账号。

## 外部项目输出

输出必须说明命中路由、读取层级、账号 Skill 状态、用户层边界、正式/候选状态和下一步。生产内容必须返回 `topic_id`、`content_id` 与账号 Skill 版本。
