# 项目调用规则

其他项目可以调用本知识库，但默认只调用已整理知识和索引，不直接读取原始数据。

## 推荐入口

优先使用全局 Skill 入口：

```text
@知识库 + 你的需求
```

如果中文入口不可用，使用兼容入口：

```text
knowledge-base + 你的需求
```

中文 Skill 源包在：

```text
/Users/lao_wu/codexAI/知识库/14_KB_System/skill_packages/知识库
```

兼容 Skill 源包在：

```text
/Users/lao_wu/codexAI/知识库/14_KB_System/skill_packages/knowledge-base
```

如果其他项目中没有显示“知识库”入口，需要把该目录同步到全局 Skill 目录：

```text
/Users/lao_wu/.codex/skills/知识库
```

或同步到目标项目的项目级 Skill 目录：

```text
<项目根目录>/.agents/skills/knowledge-base
```

## 默认入口

其他项目调用本知识库时，固定入口读取顺序以 `14_KB_System/config/skill_contract.json` 为准，并同步生成到中英文 Skill 包。

调用原则：先用总控路由判断任务类型，再按索引读取少量相关文件。`knowledge_index.json` 是全量机器索引，只给脚本、全量审计或明确要求时使用。禁止全盘扫库，除非用户明确要求。

## 调用范围

项目可以声明：

```yaml
use_main_kb: true
use_sub_kb:
  - 子库名称
use_methods:
  - 方法论名称
use_skills:
  - Skill 名称
avoid:
  - 不希望使用的领域或风格
```

## 默认优先级

1. 项目指定子知识库。
2. 主知识库方法论。
3. 平台知识。
4. 选题灵感库。
5. 趋势雷达。

## 默认禁止

除非你明确要求，其他项目不得调用：

- `00_Inbox/` 原始输入。
- `数据/` 原始爬虫数据。
- `99_Archive/` 低价值归档。
- `10_Knowledge/candidates/generated_assets/` 中未经审核的候选资产，除非任务明确要求审核候选。
- `decision != keep` 的资料。
- 未确认的 Skill 提案。
- 任何全库递归扫描或“随便找相关内容”的行为。

## 按需调用方式

- 内容创作：先查任务入口索引，再读取 `10_Knowledge/formal/methods/`、`10_Knowledge/formal/topics/`、`10_Knowledge/formal/platforms/`、`10_Knowledge/formal/content_factory/` 中相关文件。
- 知识成长/自媒体：额外读取 `10_Knowledge/formal/accounts/知识成长自媒体方法论/`。
- 复盘：读取 `10_Knowledge/formal/reviews/`、`20_User/syncable/` 和 active Skill。
- Skill 进化：只能读取 active 和 proposals，修改必须先生成 proposal。

## 推荐项目入口文件

每个项目可创建 `KNOWLEDGE_USE.md`，说明本项目如何使用知识库。

## 输出契约

其他项目调用时，输出必须说明：

- 调用入口。
- 命中路由。
- 读取层级。
- 允许使用范围。
- 禁止使用范围。
- 正式知识来源。
- 候选证据状态。
- 下一步调用建议。

默认只使用正式知识、入口索引和总控路由。候选资产、原始数据、归档资料和未确认 proposal 只能在你明确要求审核或追溯时读取。

## 长期封装方向

本知识库默认通过总控 Skill 被其他项目调用。Skill 只作为稳定调用接口；知识库本体仍持续更新和进化。其他项目默认调用 Skill/入口/总控路由/索引，不直接扫描知识库本体。
