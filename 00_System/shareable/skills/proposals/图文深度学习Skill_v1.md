# Skill 提案：图文深度学习 v1

状态：proposal，待用户确认后才能进入 active。

## 适用范围

当用户提供图文截图、图片包、图文笔记 manifest 或账号图文样本，并希望学习账号图文表达方式时，使用本提案。

本提案只定义账号学习中的图文媒介分支，不替代 `视频深度学习Skill_v1.md`，不改变账号中心正式入库规则。

## 触发条件

- 用户说“学习图文账号”“图文学习”“学习小红书图文”“分析这些图文图片”“把这些图文样本结构化后学习”。
- 用户上传或指定一组图片、截图、图文笔记目录或图文 manifest。

## 固定流程

```text
ingest -> structure -> scan -> select -> learn -> status
```

## 工作规则

1. 原始图片、截图和图文包只读。
2. 结构化结果写入 runtime cache 或候选资产，不直接写正式知识。
3. 第一版主 OCR 引擎使用 PaddleOCR；工具缺失时必须降级并保留 `ocr_status`、图片顺序、图片路径和证据缺口。
4. Pillow/OpenCV 只提取尺寸、色系、清晰度、复杂度等客观视觉特征。
5. image2 是 Codex 会话内看图能力，不是第三方 CLI；它只补图片转述和构图证据，不能替代账号学习结论。
6. 后续接入 Docling、MinerU 或其他工具时，只能适配统一 JSON 结构，不能让知识库主流程依赖某个工具的私有格式。
7. 图文学习必须区分发布内容层和图文结构层：
   - 发布内容层：标题、正文、话题、互动数据、账号方向。
   - 图文结构层：封面、分图顺序、图中文字、版式、视觉风格、转化页。
8. 图文深学卡、候选学习卡和审核清单未经用户确认不能进入正式账号中心。
9. 图文学习产出的账号风格、封面规则、分图模板和减少 AI 味规则只属于对应账号中心，不能写成通用规则。

## 输出要求

- 图文 manifest。
- 图文结构化 JSONL。
- 图文结构化报告。
- PaddleOCR 文字、文本块和 OCR 状态。
- Pillow/OpenCV 客观视觉特征。
- Codex image2 图片转述证据。
- 方向统计和方向全量粗学池。
- Top/候补图文深学清单。
- 图文深学卡。
- 候选学习卡。
- 机器审计结果和审核清单。
- 可入库建议和不能入库原因。

## 回滚方式

- 删除本 proposal 即可取消生效。
- 如果后续已确认进入 active，回滚时恢复 `controller_routes.json`、`task_entry_index.md`、`output_contracts.json` 中的图文分支说明，并删除 active Skill。
- 不删除原始图片、截图或用户提供的图文包。
