# 流派观察适配

流派适配只改变观察和验证重点，不复制整套学习流程。

- 剧情/短剧：关系、冲突发动机、升级轮次、转折、表演、镜头和收束。
- 长文案：论证主线、观点证据、段落推进、抽象时机、情绪曲线和篇幅完成条件。
- 知识口播：问题承诺、案例、解释模型、行动落点和可信度。
- 图文：按一条发布内容及其有序组图学习。发布层检查标题机制、正文结构、细节与生活痕迹、结尾、话题和视觉协同；图片层逐图检查封面、页序角色、构图、文字设计、动作状态、结果呈现、视觉质感、真人感和收藏理由。OCR 只提供文字证据，不代表图片学习完成。
- 对话/采访：说话人归属、追问推进、观点所有权和合作边界。
- 商业植入：正常内容发动机、广告引入桥、产品角色、商业载荷和广告后收束。
- 平台项目：外部项目壳、参与角色、发布任务和账号自然方法边界。

阶段 0 可多选流派；阶段 1 按单条内容分派；阶段 2 分流派聚合后再判断账号共享指纹。
