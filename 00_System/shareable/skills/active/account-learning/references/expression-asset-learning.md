# 表达资产学习

这是账号学习七阶段中的一条并行资产链，不是第二套工作流。阶段 ID、顺序、用户确认门和账号 Skill 防回退机制均保持不变。

## 目标

逐条列出并拆解发布内容和视频中的表达资产，再跨卡聚合为可检索、可审核的候选图谱：

- 钩子：开头、信息差、段落/镜头转场、冲突、证据、反转、情绪、结尾。
- 金句：命名、解释、判断、行动、身份、信任和收束功能。
- 句式：句法、节奏、连接方式和变量位。
- 结构：开头动作、结构单元、转场、证据、转折、结果和结尾动作。
- 其他：痛点、改编骨架、反例和慎用表达。

发布标题、发布正文、口播、视觉和跨模态协同必须分别记录；不能拿其中一层替代另一层。

## 七阶段接入

1. 阶段 0：只审计证据覆盖、内容层和媒介层，不开始提取。
2. 阶段 1：逐条提取并拆解资产，先生成最多 20 条的小样本。钩子必须覆盖开头和内容过程中的全过程，不能只取前三秒。
3. 阶段 2：执行真实检索、溯源、抽象、改编、风险和账号隔离验收；样本未被接受不得全量提取。
4. 阶段 3：RIA++ 方法构造可以引用资产，但不得删除或吞并来源资产。
5. 阶段 4：聚合钩子、金句、句式和完整结构图谱，并建立资产到方法的链接。
6. 阶段 5：执行检索、改编、原句复制、无证据效果承诺、跨账号污染和跨媒介错配测试。
7. 阶段 6：同时交付机器 JSONL/manifest 与中文可见拆解包，保持候选、不可调用、不可写正式层。

## 记录要求

每条资产至少包含：

- 资产类型、来源层、内容位置和功能；
- 来源登记、证据坐标与哈希；
- 来源原文与抽象模式两个独立字段；
- 模式变量与改编骨架；
- 结构可用性评分和独立的效果证据状态；
- 风险、生命周期、门禁证据和用途边界。

来源原文只可展示和检索，原文永远不可作为生成输入，`generation_eligible=false` 永久不变。候选抽象模式也不可直接生产；只有完成跨卡验证、压力测试、用户确认、正式 Skill 提案和回归后，才能另行晋升。

## 单一工作流与兼容

- active 入口只有一套七阶段流程，表达资产链内嵌其中。
- 新任务默认执行本规则。
- 以前保存的状态仍可读取和验收；继续旧任务时在同一工作流中补齐新增产物，不复制成第二条流程。
- 升级不能删除旧能力、旧产物或旧阶段证据；任何替换、弃用或语义变化都必须形成提案并经用户确认。

## 污染边界

- 系统层只保存 schema、类型、状态机、校验和验收规则，不保存账号原句、账号结论或 source_id。
- 每个包只能有一个 account_id，且来源、验证报告和性能证据必须落在同账号命名空间。
- 禁止跨账号补样本、合并模式或借用其他账号规则。
- 用户拒绝产物只能作为 `anti_pattern + rejected + validation_only`。
- 单条内容、逐字稿和主观评分不能证明传播效果。
