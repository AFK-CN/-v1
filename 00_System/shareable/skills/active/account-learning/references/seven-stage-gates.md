# 七阶段质量门

0. 整体理解：主旨、内容支柱、局限、证据和用户确认。
1. 五视角观察：定位、选题、结构、表达、反例；完成真实证据验收。
2. 机制聚合与三重验证：跨内容证据、预测指导力、账号独特性；保留淘汰原因并等待用户确认。
3. RIA++：原始证据、解释、已发生案例、未来触发、执行和边界。
4. 方法链接：只建立真实依赖、对比和组合关系。
5. 压力测试：正例、负例、边界、跨场景、词汇诱饵、兄弟干扰和商业污染均保存逐案例结果。
6. 候选交付：学习精华、promotion manifest、生产交接和账号 Skill 候选保持不可调用；视觉分支还必须完成同账号原始资产的生产角色/风险覆盖参考候选，正例、用户偏好和反例来源隔离后再等待正式审核。
