# Skill：JSON 入库 v1

状态：active，已由你确认生效。

## 适用场景

你新增或指定 JSON 文件，尤其是小红书、抖音爬虫数据、评论数据、创作者数据。

## 工作规则

每次新增 JSON：

1. 不修改原始文件。
2. 识别平台和数据类型。
3. 统计总数、字段、缺失值、重复 ID。
4. 指标字段统一转数字。
5. 执行 ID 去重和文本指纹去重。
6. 输出 keep/review/archive/discard 决策。
7. 只把代表记录和方法论证据写入正式知识库。

## 输出要求

- 数据盘点。
- 去重统计。
- 噪音和无效信息判断。
- 可进入方法论/选题/子库的候选内容。
- 需要你确认的新增子库或规则变更。

## 风险控制

- 近似去重不能直接删除原始资料。
- 指标高不等于内容一定适合你，要结合领域、平台和账号方向。
- 清洗结果如果有误，只重建派生产物，原始 JSON 不动。
