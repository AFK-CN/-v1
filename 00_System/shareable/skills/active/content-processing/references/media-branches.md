# 媒介分支

## 视频

重点处理下载、逐字稿、说话人、抽帧、镜头、表演、场景、广告段和时间码。

## 图文

最小处理单位是一条真实发布内容，不是一张散图。必须保留 source_id、原链接、发布标题、完整正文、显式话题和有序图片组；缺失字段明示，不能从 OCR 或图片内容补造。

逐图保留原图路径、页序、OCR、客观视觉特征和视觉复核状态。OCR 只证明图中文字，不能代替构图、视角、文字注释设计、字形字号层级、动作状态、结果呈现、真人与生活感或组图叙事。

散图兼容输入必须标记 `post_grouping_unknown` 和 `publish_layer_missing`，不得学习分图顺序或发布文案规律。图文学习与图文成品生图是两条流程。

推荐的 `posts.jsonl` 每行是一条发布记录：

```json
{"source_id":"稳定来源ID","url":"原链接","title":"发布标题原文","caption":"发布正文全文","tags":["显式话题"],"images":["01.jpg","02.jpg","03.jpg"]}
```

`images` 顺序即发布页序；没有显式话题但已确认来源确实为空时写 `"tags": []`，不要省略字段。图片路径可相对 `posts.jsonl` 或输入目录。

## 结构化数据

重点处理字段映射、稳定主键、增量指纹、缺失值、重复记录和来源链接。结构化数据只负责建立候选入口，不能自动成为正式知识。
