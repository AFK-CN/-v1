# Skill：视频深度学习 v1

状态：active，已由你确认生效。
适用范围：通用内容学习流程，不绑定任何单一账号。账号专属风格、表达模板、去 AI 味规则仍留在对应账号中心。

## 适用场景

当你新增或指定视频、图文元数据、账号内容、抖音/小红书内容数据后，需要：

1. 扫描内容方向。
2. 筛选 Top 内容。
3. 生成深度学习卡。
4. 形成候选学习卡和审核清单。
5. 经用户确认或审核注册表通过后，再沉淀为正式知识。

## 工作规则

1. 原始数据只读，候选学习资产写入 `10_Knowledge/candidates/`，运行报告、状态和缓存写入 `00_System/runtime/`，临时队列写入 `90_Temp/`。
2. 每次学习先跑轻量扫描，输出方向统计和方向榜单。
3. 每个方向保留 Top 内容，不用单一总榜替代方向榜。
4. 小红书热度分：`收藏 * 0.45 + 点赞 * 0.3 + 分享 * 0.15 + 评论 * 0.1`。
5. 抖音热度分：`分享 * 0.3 + 收藏 * 0.3 + 评论 * 0.2 + 点赞 * 0.2`。
6. 高置信内容只能先进入候选学习卡和审核清单。
7. 正式方法论、选题库、内容模板或账号中心写入，必须经过用户确认或已验证审核注册表。
8. 新子库仍只进入 `10_Knowledge/candidates/sub_kbs/`，不能自动进入正式账号或子库目录。
9. 视频分析工具缺失时降级为元数据学习，不中断扫描。
10. 账号级产物必须从本账号标题、正文/文案、话题、内容结构、单卡和方向总结归纳；除非用户明确要求对比分析，不得在一个账号的正式文件中写入另一个账号名称、风格或“不同于某账号”的表述。
11. 学习证据必须分层：粗扫/粗学阶段只学习发布内容层，包括标题、正文/文案、话题/标签和内容结构协同，因为此时通常还没下载视频；深度学习阶段才完整学习发布内容层和视频内容层，视频内容层包括下载后产生的逐字稿、抽帧/分镜和视频层表达。两个层级不能混写，缺失时必须在审计报告中标注。

## 输出要求

- 方向统计和方向榜单。
- Top 内容清单。
- 粗扫/粗学输出：发布内容层学习结论，包括标题、正文/文案、话题/标签、内容结构协同。
- 深度学习输出：完整学习结论，包括发布内容层和视频内容层；视频内容层覆盖逐字稿、抽帧/分镜、视频层表达，若缺失则写明降级状态。
- 深度学习卡。
- 候选学习卡。
- 审核清单或审核注册表。
- 可正式沉淀内容的建议位置。
- 不能沉淀或需要补证据的内容。

## 通用规则与账号规则边界

通用规则包括：

- 原始资料只读。
- 候选学习卡先于正式入库。
- 正式入库必须审核。
- 用 `source_id`、原链接、审核注册表防重复。
- 新子库不能自动创建为正式子库。

账号专属规则不写入本 Skill，包括：

- 某个账号的表达风格。
- 某个账号的反 AI 味规则。
- 某个账号的内容输出模板。
- 某个账号的方向优先级。
- 某个账号的单卡、逐字稿和方法论总览。

账号产物生成边界：

- 通用系统只规定学习流程、证据层级、审核门禁和输出结构。
- 账号中心文件只能记录该账号自身规律；不能用另一个账号作参照来定义本账号。
- 防 AI 味规则必须来自本账号正式学习证据，不能复制其他账号模板后替换名称。

## 风险控制

- 高指标不等于内容一定适合本账号，要结合领域、平台、账号方向和发布反馈判断。
- 视频链接可能过期，无法下载时降级为元数据学习。
- 候选内容可能重复，必须通过 `video-learning` 标记、`source_id` 和审核注册表防重复。
- 深度学习卡不是正式知识，未经审核不能直接用于长期方法论沉淀。

## 回滚方式

- 删除候选学习卡、审核清单，或删除正式知识库中经确认后追加的 `video-learning:confirmed-method`、`video-learning:confirmed-topic`、`video-learning:confirmed-template` 标记区块。
- 删除 `10_Knowledge/candidates/` 下对应候选学习卡、`00_System/runtime/` 下对应运行产物或 `90_Temp/` 下对应队列后可重新生成。
- 不修改原始 JSON、视频、截图或 `数据/`、`00_Inbox/`。
