# 记忆判定规则

记忆系统是系统级能力，但具体记忆内容必须按边界分层保存。

## 可写入记忆的信息

- 用户明确纠正过、未来会复用的规则。
- 已验证通过的路径、命令、流程和边界。
- 会影响后续决策的项目决策。
- 已解决问题的原因、修复方式和验证证据。
- 智能体调用边界、能力范围和权限限制。

## 自动判断规则

系统可以在任务结束或对话中自动判断是否生成记忆候选，但不是每次结束都生成。

触发候选的强信号：

- 用户纠正规则或边界。
- 用户表达“以后/默认/每次/长期”。
- 问题已解决并有验证结果。
- 出现稳定流程或重复问题。
- 智能体能力、权限、登录、记忆边界发生变化。
- 用户明确说“记住、沉淀、会话总结”。

跳过候选的情况：

- 普通结束语、感谢、闲聊。
- 一次性方案、临时过程。
- 用户明确说不用记或不要沉淀。
- 没有复用价值或未验证的中间判断。

## 不写入记忆的信息

- 一次性聊天过程。
- 未确认猜测和临时方案。
- 密钥、token、密码、App Secret、refresh token。
- 未经验证的结论。
- 可从索引或代码直接推导、没有复用价值的细节。

## 分层规则

- 系统规则、schema、流程：`00_System/shareable/memory/`。
- 用户长期偏好和决策：`20_User/syncable/memory/`。
- 本机私有路径、账号和凭证位置提示：`20_User/private/`。
- 会话摘要、问题复盘、证据链：`10_Knowledge/evidence/memory/`。
- 未确认候选：`00_System/runtime/memory/`。
