# 项目调用规则

其他项目可以调用本知识库，但默认只调用已整理知识，不直接读取原始数据。

## 调用范围

项目可以声明：

```yaml
use_main_kb: true
use_sub_kb:
  - 子库名称
use_methods:
  - 方法论名称
use_skills:
  - Skill 名称
avoid:
  - 不希望使用的领域或风格
```

## 默认优先级

1. 项目指定子知识库。
2. 主知识库方法论。
3. 平台知识。
4. 选题灵感库。
5. 趋势雷达。

## 默认禁止

除非你明确要求，其他项目不得调用：

- `00_Inbox/` 原始输入。
- `数据/` 原始爬虫数据。
- `99_Archive/` 低价值归档。
- `decision != keep` 的资料。
- 未确认的 Skill 提案。

## 推荐项目入口文件

每个项目可创建 `KNOWLEDGE_USE.md`，说明本项目如何使用知识库。
