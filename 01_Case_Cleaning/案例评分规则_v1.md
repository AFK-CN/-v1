# 案例评分规则 v1

## 分数

```yaml
relevance_score: 是否服务小红书/抖音自媒体创作
viral_score: 指标是否强，是否超过同批样本中位数或 p90
topic_score: 是否能延展出多个选题
novelty_score: 是否有新角度、新表达、新结构
reuse_score: 是否能被复用为模板、脚本、标题、栏目
noise_score: 噪音程度，越高越不该入库
```

## 决策

- `keep`：进入案例卡、方法论、选题库、子库候选。
- `review`：价值不确定，需要你判断。
- `archive`：低价值或重复，只保留索引。
- `discard`：无效信息，不进入知识库。

## 平台权重

小红书：

- 收藏权重大于评论。
- 清单、步骤、可照做内容优先。
- 生活场景、身份标签、人群标签加分。

抖音：

- 分享、评论、收藏都重要。
- 强观点、强开头、强行动建议加分。
- 评论区高赞复述或补充，说明内容击中共识。
