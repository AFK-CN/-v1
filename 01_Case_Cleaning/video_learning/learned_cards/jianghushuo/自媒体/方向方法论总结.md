## 1. 方向核心判断

姜胡说的自媒体方法不是单点涨粉术，而是一条完整链路：

`真实经历 -> 有用内容 -> 对话反馈 -> 信任积累 -> 内容资产 -> 产品与一人公司杠杆`

流量只是让用户第一次看见，长期价值来自三件事：内容是否解决真实问题、创作者是否值得信任、内容能否被持续调用。

## 3. 共性方法论

1. 真实经历起号：优先讲自己解决过的问题，不先制造空人设。
2. 试用装内容：完整交付一个可验证的小结果，用兑现积累信任。
3. 对话场运营：开场建立关系，正文制造代入，评论沉淀下一轮选题。
4. 资产型内容：围绕长期问题生产“场景—原因—方法”内容，而非只追热点。
5. AI 研究矩阵：用多模型、多年龄、多场景扩大理解，再由人筛选和验证。
6. 内容商业闭环：用 AIDA 从注意走到行动，把内容接入产品与服务。
7. 一人公司杠杆：把技能写成函数，通过内容提高调用频次并沉淀自动交付资产。

## 4. 常见内容结构

- 反常识判断 -> 真实案例 -> 原因解释 -> 可执行步骤 -> 边界或金句。
- 明确人群 -> 数量承诺 -> 三点清单 -> 反向筛选 -> 系统收束。
- 具体困境 -> 决策摇摆 -> 失败动作 -> 调整过程 -> 当前解法。
- 用户场景 -> 为什么发生 -> 自己如何验证 -> 用户现在能做什么。

## 5. 高频黄金 3 秒钩子类型

- 定义反转：“你不是在创作内容，而是在创造对话场。”
- 结果反差：“有流量和能赚钱，是两回事。”
- 方法命名：“伤疤起号法。”
- 数量承诺：“普通人就做三件事。”
- 身份升级：“你自己就可以是一家公司。”
- 产能承诺：“一天可以拍十条视频，秘诀是……”

## 6. 常见收尾与互动方式

- 大多数样本以价值判断或行动建议收束，明确评论引导较少。
- 已确认的一类互动是回忆式提问：“你过去最棒的一次对话是怎么发生的？”
- 更适合本方向的自然提问包括：你解决过什么真实问题、你卡在哪一步、哪一条经验能先做成试用装。
- 没有证据的单卡统一标记“未明确”，不补造互动话术。

## 7. 可复用选题池

- 为什么高质量内容没人看：你缺的可能是对话感。
- 普通人起号，不要先定位，先列过去三年解决过的问题。
- 免费分享会培养竞争对手吗？真正复制不了的是信任。
- 有流量却赚不到钱，先检查价值和信任。
- 一条三年后仍有用的视频，应该包含哪四部分？
- AI 怎么帮创作者扩展角度，而不是批量制造同质稿？
- 一个人如何把短视频、橱窗、专栏和社群变成一家公司？
- 你的技能函数是什么：输入、处理、输出、谁付费？
