# 内容生产模板 v1

## 小红书图文模板：收藏型清单

```text
标题：
{人群/场景} + {周期/数量/指南} + {明确收益}

正文结构：
1. 一句话说明适合谁。
2. 给完整清单或步骤。
3. 补充执行注意点。
4. 评论区提问，收集下一批问题。

封面方向：
大标题 + 结果承诺 + 清单视觉。
```

适用：

- 一周减脂餐。
- 备餐指南。
- 工具清单。
- 学习计划。

## 抖音口播模板：强观点行动型

```text
开头：
一句反常识观点。

展开：
为什么大多数人做错了。

方法：
给 1-3 个具体动作。

例子：
用普通人的场景解释。

收束：
一句可复述的金句或行动号召。
```

适用：

- 自媒体行动。
- 知识成长。
- 普通人副业。
- 复盘方法。

## 评论复盘转选题模板

```text
评论原话：
用户到底在重复什么、补充什么、反驳什么？

需求判断：
这是情绪共鸣、方法需求、案例需求，还是反对意见？

下一条选题：
把评论中的问题改写成一个内容承诺。

平台改写：
小红书：清单/步骤/模板。
抖音：观点/冲突/行动。
```

## 第一阶段视频深度学习模板：单场景反差短剧

<!-- selected-video-learning:template:single-scene-contrast-sketch:v1 -->

适用方向：短剧、职场喜剧、关系喜剧、生活荒诞反转

```text
标题：
{一个日常空间/职业身份} + {两种状态/反差结果}

脚本结构：
1. 直接进入熟悉场景，不解释背景。
2. 用第一个动作/站位/话术建立观众预期。
3. 让身份错位或关系反差出现。
4. 每 2-5 秒升级一次误会、动作或台词。
5. 结尾不讲道理，留一个荒诞状态或评论区站队点。

拍摄重点：
单场景即可，但要保证表演、站位、字幕和节奏能让观众秒懂反差。
```

## 第一阶段视频深度学习模板：强观点行动系统口播

<!-- selected-video-learning:template:strong-opinion-action-system:v1 -->

适用方向：个人成长、自媒体、AI、赚钱、普通人行动系统

```text
标题：
{普通人/你} + {明确时间/数量承诺} + {改变结果}

脚本结构：
1. 开头先给强判断或强结果承诺。
2. 指出大多数人的一个错误做法。
3. 用个人经历、普通人场景或具体例子证明。
4. 给 1-3 个最小可执行动作。
5. 用一句可复述的行动原则收束。

改写方式：
抖音用强观点和冲突开头；小红书改成清单、步骤、每日动作表。
```
