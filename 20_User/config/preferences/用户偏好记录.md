# 用户偏好记录

只记录用户明确确认、会影响本知识库工作的稳定偏好。

- 原始资料不删除、不修改；默认不扫描原始数据目录。
- 批量机械工作交给本地代码，Codex 负责路由、验收和异常审核。
- 复杂系统变更先规划；完成后必须重建索引、运行全量测试、系统校验、边界干跑和污染扫描。
- 账号粗学产物必须是完整选题池，Top/候补只是优先级视图。
- 账号学习的主产物是可读的精修单卡与最终账号 Skill，不是机器中间包。
- 系统层保持通用；账号结构、表达、方向和边界只进入对应账号 Skill。
- 用户层就是本机层；系统负责定义和初始化结构，不复制其他用户真实数据。
- 选题、内容和反馈使用结构化生产记忆；模型不读取完整数据库。
- 默认不做会话自动记忆或 Skill 自动进化；账号 Skill 更新必须来自复盘证据并经用户确认。
- 只在用户明确要求时使用真实多智能体或子任务。
- 小红书正式证据使用 `xhs_` 前缀，不能默认沿用抖音前缀。
