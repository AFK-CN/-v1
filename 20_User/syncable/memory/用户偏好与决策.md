# 用户偏好与决策

这里记录可同步的长期偏好、已确认决策和跨会话复用规则。

## 当前记录

- 记忆系统采用“系统规则集中、内容分层保存、入口集中导航”的结构。
- 智能体登录和凭证状态属于本机私有内容，不进入可分享系统层。
- 当前项目记忆只在本知识库项目内复用，不写入全局记忆，不跨项目套用。
- 系统可以自动判断是否生成记忆候选，但候选只进入 runtime pending，长期记忆需要确认后再沉淀。
- 用户更偏好脚本批量处理、Codex 审核异常；不要让 Codex 手动扫原始数据。
- 会话外调用能力要用最小测试验证，不能依赖当前会话上下文。
- 知识库账号资料清洗与学习流程默认采用单执行器口径：主 Codex 负责判断和验收，本地代码负责批量执行，阶段工作流记录进度和结果；只有用户明确要求多智能体/子任务时，才启用真实多智能体。
