# Inbox 使用说明

后续新增资料先放这里，或继续放在你指定的数据目录。

推荐命名：

```text
YYYY-MM-DD_platform_type_topic.ext
```

例子：

- `2026-06-20_xhs_contents_food.json`
- `2026-06-20_douyin_export_accountA.xlsx`
- `2026-06-20_xhs_screenshot_note123.png`
- `2026-06-20_manual_feedback.md`

## 放进来后 AI 要做什么

1. 判断资料类型。
2. 保留原始文件不动。
3. 生成清洗摘要。
4. 去重。
5. 决定进入方法论、选题库、周复盘、用户偏好、Skill 提案或归档。
